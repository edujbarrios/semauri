# Semauri v0.24.0 — Typed Scoped List Pipelines

Semauri 0.24.0 extends the Rust compiler from fixed list operators to type-checked, lexical-scope **element-wise transformations** and bounded integer list generators.

## Map with inferred element type

```sema
let readings be a list of 2, 3, 5.
let doubled be map every n in readings to (n times 2).
assert (doubled at 0) is equal to 4.
```

The compiler introduces a fresh, immutable iterator binding scoped to the transformation body. The body can use other immutable outer variables. It infers `list<T> -> list<U>` statically; transformations can produce numbers, strings, Booleans and nested lists. The input is evaluated once, and its source list is never modified.

## Filter with checked Boolean predicates

```sema
let readings be a list of 2, 3, 5, 8.
let selected be filter every n in readings if (n is greater than 3).
assert length of selected is equal to 2.
```

The predicate must return Boolean (S366 on mismatches) and the input must be a list (S365). Filtering retains the original list type and order. Empty results remain typed, and the scoped iterator name does not escape the expression. Both map and filter are contextual constructs: identifiers named `map` or `filter` remain valid unless followed by `every`. Body evaluation is pure over compiler-known data.

[Feature PR #169](https://github.com/edujbarrios/semauri/pull/169) · [Complete semantics](../33_MAP_FILTER.md)

## Range generation for composable pipelines

```sema
let values be range from 1 to 8.
let squares be map every n in values to (n times n).
let even_squares be filter every n in squares if ((n modulo 2) is equal to 0).
print even_squares.
```

Range endpoints are included. The compiler emits a new immutable `list<number>` holding exact i64 values, ascending or descending as required. Both endpoints must be typed numbers (S367) represented as integers (S368 for decimals), and the result is bounded to **10,000 elements** (S368 for oversize requests). i128 arithmetic safely handles the entire i64 endpoint domain without overflow. `range` is contextual, preserving legacy variable names.

[Feature PR #170](https://github.com/edujbarrios/semauri/pull/170) · [Complete semantics](../34_INTEGER_RANGE.md)

## Examples and compatibility

```sh
semauri version
semauri check examples/map_filter.suri
semauri check examples/range_map_filter.suri
semauri run --allow console_write examples/map_filter.suri
semauri run --allow console_write examples/range_map_filter.suri
```

Expected version: `Semauri 0.24.0`.

**Scope:** This is a static, concrete-data compiler, not a general-purpose runtime for arbitrary datasets, tensors or model training. `map`, `filter` and `range` are **not** user-defined functions or arbitrary higher-order lambdas. The ML domain still produces typed workflow plans and reproducibility audits, not actual training.

The distribution workflow publishes native binaries for Windows, macOS and Linux (ARM64 and x86_64) along with SHA256SUMS after smoke tests. Verify [the v0.24.0 release](https://github.com/edujbarrios/semauri/releases/tag/v0.24.0) and [installation guide](../00_INSTALLATION.md) before sharing the binaries.
