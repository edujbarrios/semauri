# Semauri 0.75.0 — Secure passwords and random generation

Release date: 2026-11-11.

## New built-in random generation

Semauri can now generate passwords, tokens, uniform integers and random
Unicode characters without needing another language or a third-party package:

```text
let generated_password be password of 20 characters.
let custom_token be secure random string of 32 characters from "abcdef0123456789".
let dice_roll be draw random integer from 1 to 6.
let selected_letter be pick random character from "ABCD".
print generated_password.
```

[Run the working example](../../examples/secure_password.suri):

```sh
semauri run examples/secure_password.suri --allow secure_random --allow console_write
```

### Security and correctness

- Cryptographic OS-provided randomness: `/dev/urandom` on Linux and macOS,
  and `BCryptGenRandom` using the Windows system-preferred RNG.
- Rejection sampling, avoiding modulo bias in selections even when alphabet
  lengths or integer ranges do not divide a power of two.
- Exact inclusive signed 64-bit integer bounds, including large values beyond
  2^53, and Unicode scalar-aware character selection.
- One to 4096 characters per generated password/string, unique custom alphabet
  characters only; malformed lengths, duplicate/empty alphabets and invalid
  integer ranges fail with source-located runtime errors.
- Explicit `--allow secure_random` capability. Compiler and plan metadata
  do not contain generated secret values; printed secrets still need cautious
  handling. No silent fallback to a predictable pseudo-random seed.
- No new Rust dependencies.

## Tooling and compatibility

- README password walkthrough, runnable example, language guide, VS Code
  syntax highlighting and Jupyter completion keywords updated.
- Rust regression tests cover static type rejection, Unicode characters,
  length bounds, effect permissions, repeated independent generation,
  numeric ranges, editor formatting and runnable examples.
- This release includes PR [#346](https://github.com/edujbarrios/semauri/pull/346)
  and retains the improvements from v0.74.0.

**Note:** Passwords are selected independently from an alphabet; the default
alphabet includes upper/lowercase ASCII, numbers and common symbols but does
not force every class to appear. Use a sufficient length (20+ recommended) and
avoid exposing generated secrets in console logs.
