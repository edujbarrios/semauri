# Semauri 0.13.1

0.13.1 republishes Semauri after the reference compiler migration from Ruby to Rust.

## Distribution fix

- Official archives are built from the native Rust compiler.
- The release uses a new version instead of reusing the legacy `v0.13.0` artifacts.
- Cargo dependencies are locked for reproducible application builds.
- CI now verifies Rust formatting and uses locked dependency resolution.

The language surface remains compatible with 0.13.0; this patch release corrects the distributed implementation and release process.
