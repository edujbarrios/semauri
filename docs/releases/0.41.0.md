# Semauri 0.41.0

Semauri 0.41.0 completes another part of the language's Unicode-aware
text processing toolkit. Users can now retrieve every non-overlapping
substring position as a typed list, or find the rightmost occurrence of
a substring using readable English syntax.

## New: Find every substring position

`positions of NEEDLE in TEXT` produces a statically typed `list<number>`
of zero-based **Unicode scalar** offsets. A missing substring returns
a typed empty list; matches are case-sensitive and non-overlapping.

```text
let places be positions of "é" in "café café".
assert length of places is equal to 2.
assert (places at 0) is equal to 3.
assert (places at 1) is equal to 8.
```

The needle must be nonempty. The operation is bounded to 10,000 matches
to avoid unbounded list expansion. Invalid empty needles and excessive
matches report a located `S415` error, and invalid operand types
report `S414` during static checking.

## New: Find the rightmost substring position

`last position of NEEDLE in TEXT` yields the zero-based Unicode scalar
offset of the rightmost match, or `minus 1` if none is found.
The empty needle returns the Unicode scalar length of the source.

```text
assert last position of "a" in "café a" is equal to 5.
assert last position of "missing" in "café" is equal to minus 1.
assert last position of "" in "café" is equal to 4.
```

Rightmost matching may overlap earlier matches, so for `"aa"` in
`"aaaaa"` the last position is 3, whereas the all-positions
(non-overlapping) list is `[0, 2]`.

## Architecture and compatibility

Both expressions are pure and deterministically type-checked. Match
offsets use Unicode scalar values, not UTF-8 byte indices, locale-sensitive
collation, or grapheme clusters. The all-position matcher advances through
the text incrementally rather than repeatedly scanning prefixes, and the
compiler folds successful constant list and scalar expressions.

This release updates the Rust compiler, parser, HIR types, evaluator,
optimizer, formatter, VS Code grammar, documentation, tests, and runnable
examples. Operators are contextual: previously valid variable names
continue to work. No new dependencies or effect permissions are required.

## Install and verify

Download the package for your platform from the GitHub release. Linux,
macOS and Windows archives are provided for x86_64 and ARM64, together
with `SHA256SUMS` for verifying archive integrity.

The release includes the full functionality of Semauri 0.40.0 and earlier
versions, including Unicode character indexing, substring removal, typed
JSON extraction, JSON pointers, and explicit effect analysis.

See `README.md` for canonical syntax and `CHANGELOG.md` for changes.
