# Semauri 0.66.1 — Consolidated stable binaries

Semauri v0.66.1 is a **repackaging release** requested after v0.66.0,
with **no language or runtime behavior changes** since v0.66.0.
The compiler, parser, optimizer, formatter, examples, tests and Jupyter
integration retain the same functionality.

This patch release carries all the enhancements already shipped in
[v0.66.0](0.66.0.md), introduced in pull requests
[#316](https://github.com/edujbarrios/semauri/pull/316) through
[#327](https://github.com/edujbarrios/semauri/pull/327).

## Language improvements included

- Checked natural-language numeric signs, negated bounds, and Unicode text
  prefix/suffix predicates.
- Concise numeric/statistical, text and typed-list aliases.
- Ascending/descending sorting, sorted distinct/unique lists, and
  top/bottom N selection including distinct values.
- `cardinality of`, `count distinct of` and `count unique of` for typed lists.
- Unicode-safe `take first`/`drop first` and `take last`/`drop last`
  for text and typed lists.

## Packaging and compatibility

- The CLI and library version is updated to **0.66.1**.
- Jupyter kernel adapter remains **0.11.0** and supports Semauri
  language **0.66**, unchanged.
- Existing effects, capabilities, exact 64-bit integer ordering,
  diagnostics and source-compatibility guarantees are unchanged.
- Six native binaries are provided: Linux (x86_64/ARM64),
  macOS (x86_64/ARM64), Windows (x86_64/ARM64).
  Check the accompanying `SHA256SUMS` file to verify each download.

For all functional changes, see the
[Semauri v0.66.0 release notes](0.66.0.md)
and the [language guide](../language-guide.md).
