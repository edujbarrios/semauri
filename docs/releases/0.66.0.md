# Semauri 0.66.0 — Expressive natural-language collections and predicates

This release gathers improvements merged after v0.65.0 in pull requests
[#316](https://github.com/edujbarrios/semauri/pull/316) through
[#327](https://github.com/edujbarrios/semauri/pull/327).

## Natural-language predicates

- `is nonzero`, `is nonnegative`, and `is nonpositive` (also `is not`)
  use checked sign comparisons.
- `is not above`, `is not below`, `is not at least`, and
  `is not at most` preserve exact integer comparison.
- `begins with`, `finishes with`, `does not begin with`, and
  `does not finish with` provide typed, case-sensitive Unicode text tests.

## Sorted, ranked, and distinct collections

- `sorted ascending of LIST` and `sorted descending of LIST`, plus
  `sort ascending/descending of`, request an explicit order.
- `sorted unique of LIST`, `sorted distinct of LIST`, `sort unique of LIST`
  and `sort distinct of LIST` sort and deduplicate.
- `top COUNT from LIST` and `bottom COUNT from LIST` select extrema.
  `top unique COUNT from LIST`, `top distinct COUNT from LIST` and
  their `bottom` variants also deduplicate.
- `cardinality of LIST`, `count distinct of LIST`, and
  `count unique of LIST` count distinct typed values.

## List, text and statistics expressions

- `take first COUNT from VALUE` and `drop first COUNT from VALUE` explicitly
  select or remove the first N list elements or Unicode scalars.
- `take last COUNT from VALUE` selects the final N list elements or
  Unicode scalars in their original order; `drop last COUNT from VALUE`
  removes them without modifying the input.
- `med of` and `prod of` alias typed median and product.
- `rev of`, `sort of`, and `flat of` alias typed reverse, sorted
  and one-level flatten.

## Compatibility and downloads

- These expressions reuse existing checked operations: no new Rust
  dependencies, implicit runtime permissions or mutation of input values.
  Precise signed-64-bit ordering and source-aware diagnostics are retained.
- New executable examples and Rust regressions cover type checking,
  evaluation, errors, formatting, optimization and effects.
- VS Code syntax highlighting, Jupyter offline completion/help, and the
  language guide are updated.
- Release archives target Linux x86_64/ARM64, macOS x86_64/ARM64,
  Windows x86_64/ARM64. Use `SHA256SUMS` to verify downloads.
