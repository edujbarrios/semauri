# Semauri 0.19.0 — Typed Sequence and Data Processing

Semauri is a statically typed programming language with readable structured-English syntax, a native Rust compiler and explicitly authorized runtime effects. Version **0.19.0** extends its practical core-language capabilities for transforming sequences and aggregating numeric data.

## New: immutable `reverse of`

```sema
let values be a list of 10, 20, 30.
let backwards be reverse of values.
assert (backwards at 0) is equal to 30.
assert (values at 0) is equal to 10.
print reverse of "Semauri".
```

Reverses strings (by Unicode scalar value) and homogeneous typed lists, returning a new value rather than mutating the source. The compiler preserves list element types and reports `S352` for non-sequence operands. String reversal is not grapheme-cluster-aware. New source, optimizer, formatting and evaluation tests are included. [PR #154](https://github.com/edujbarrios/semauri/pull/154) · [Specification](../24_REVERSE.md).

## New: typed numeric `sum of` and `average of`

```sema
let scores be a list of 2, 4, 6.
let total be sum of scores.
let mean be average of scores.
assert total is equal to 12.
assert mean is equal to 4.
print total.
print mean.
```

These expressions accept `list<number>`, return a numeric value and can be composed with existing list expressions. Checked integer addition preserves exact results beyond the 53-bit `f64` precision limit. Means and decimal sums follow existing floating-point semantics. Invalid operands produce `S353`; overflow, empty means or non-finite results produce `S354`. [PR #155](https://github.com/edujbarrios/semauri/pull/155) · [Specification](../25_NUMERIC_AGGREGATIONS.md).

## Stability and compatibility

- Both language features are pure and require no new runtime capabilities or dependencies.
- The new reserved keywords `reverse`, `sum`, and `average` can no longer serve as bare user variable names. Previously valid programs using those exact names may need renaming.
- Lowercase remains the canonical source style; recognized commands remain case-insensitive.
- Numeric reductions operate on concrete core-language lists, **not** external tensors, ML model outputs or runtime-produced dataset handles.
- Other capabilities from v0.18.0 remain available, including typed expressions, assertions and testing, JSON/HTML backends, ML planning/dataflow analysis and the beginner-first installation guide.

## Get started

Open PowerShell (Windows) or Terminal (macOS/Linux), follow the [installation guide](../00_INSTALLATION.md), then create a plain-text `.sema` source file.

```sh
semauri version
semauri check my_program.sema
semauri run --allow console_write my_program.sema
```

Expected version string: `Semauri 0.19.0`. The [first-program tutorial](../23_FIRST_PROGRAM.md) covers editors, folders, permissions and troubleshooting.

## Native distributions

Six native release archives are built and smoke-tested in CI for Linux, macOS and Windows (x86_64/ARM64). Verify downloaded archives against the companion `SHA256SUMS` file.
