# Semauri v0.30.0 — Checked Numeric Operators

Semauri 0.30.0 adds two pure, statically typed numeric operators with source-aware error diagnostics, exact signed integer behavior and composability with existing functions and list pipelines.

## Absolute values without integer precision loss

```sema
let delta be minus 9007199254740993.
let magnitude be absolute of delta.
assert magnitude is equal to 9007199254740993.
```

`absolute of` handles typed `number` values. The i64 implementation uses checked absolute value without f64 conversion; invalid operand types receive `S386`, while signed i64 minimum overflow and non-finite values produce `S388`. The optimizer folds valid numeric literals and preserves invalid expressions for diagnostic evaluation. `absolute` is contextual: bare identifiers continue working.

[PR #188](https://github.com/edujbarrios/semauri/pull/188) · [Specification](../46_ABSOLUTE_NUMBERS.md)

## Checked list multiplication

```sema
let factors be a list of 2, 3, 4, 5.
let factorial be product of factors.
assert factorial is equal to 120.
```

`product of` accepts `list<number>` and produces `number`. Integer-only lists are multiplied using exact overflow-checked i64; the empty typed list yields integer `1`. Mixed or decimal lists use binary64 with finiteness checks. Invalid types receive `S353`, and arithmetic overflow/non-finite products raise `S387`. `product` is contextual so existing identifiers keep working.

[PR #189](https://github.com/edujbarrios/semauri/pull/189) · [Specification](../47_PRODUCT_REDUCTION.md)

## Try it

```sh
semauri version
semauri check examples/absolute.sema
semauri check examples/product.sema
semauri run --allow console_write examples/absolute.sema
semauri run --allow console_write examples/product.sema
```

The CI checks Rust regression tests and native distribution jobs for Linux, macOS and Windows on x86_64 and ARM64. The GitHub Release publishes six platform packages plus `SHA256SUMS`, after smoke testing.

**Scope:** These operations evaluate compiler-known typed values. They do not implement executing neural-network training, streaming datasets, GPU tensors or arbitrary runtime dependent code.
