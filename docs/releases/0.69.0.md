# Semauri 0.69.0 — JSON formatter reports

Semauri 0.69.0 improves editor, agent, and CI integration with the canonical
formatter, without changing the language grammar or runtime permissions.

## New formatter interface

- `semauri fmt FILE --json` previews the formatted text in a
  `formatted` field without modifying the file.
- `semauri fmt FILE --check --json` and
  `semauri fmt PROJECT --check --json` return a JSON report that includes
  `ok`, `status`, `mode`, `files_checked`, `files_changed`, and
  `changed_files`; exit status 1 still means changes are required.
- `semauri fmt FILE --write --json` and the directory equivalent report
  the paths that were actually rewritten.
- Lexical and usage errors return structured `diagnostics` when JSON mode
  was requested. Existing human-readable formatting and error behavior
  remains unchanged without `--json`.

Directory formatting still validates source before any write, skips symlinks
and excluded cache folders, and enforces the same size/file limits.

## Verification and distribution

Rust integration tests cover file preview/check/write, directory check/write,
no-change runs, invalid-source diagnostics, and file preservation.
The regular multi-platform CI and release workflows apply. No new Rust
dependencies, syntax, capabilities, or effects are introduced.
