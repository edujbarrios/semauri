# Semauri v0.23.0 — Typed List Selection and Slices

Semauri 0.23.0 extends the Rust compiler's immutable, typed collection operations with first/last element selection and count-bounded list slicing.

## First and last elements

```sema
let readings be a list of 8, 3, 5.
let first_reading be first of readings.
let last_reading be last of readings.
assert first_reading is equal to 8.
assert last_reading is equal to 5.
```

The operations preserve static `list<T> -> T` typing across numbers, strings, booleans and nested lists, do not mutate source bindings, and have no additional effect permissions. Non-list types produce `S361` and an empty list produces `S362` at evaluation. Existing programs with variables named `first` or `last` remain valid: both words act as **contextual operators** only as `first of` or `last of`. The formatter also preserves those words in other identifier and label contexts.

[PR #166](https://github.com/edujbarrios/semauri/pull/166) · [Semantics](../31_LIST_BOUNDARIES.md)

## Take and drop

```sema
let readings be a list of 8, 3, 5, 1.
let prefix be take 2 from readings.
let suffix be drop 2 from readings.
assert length of prefix is equal to 2.
assert first of suffix is equal to 5.
```

`take COUNT from LIST` keeps up to COUNT elements, and `drop COUNT from LIST` skips up to COUNT. Both produce `list<T>`, preserve source order, support nested values, and never mutate the original list. A count of zero and a count larger than list length are valid (the result can be an empty typed list). Counts must be non-negative integers; type mismatches produce `S363` during static validation, while invalid integer/fractional values raise `S364` during evaluation. Parenthesize compound operands, for example `take (1 plus 2) from (sorted of readings)`.

`take`, `drop`, and `from` are newly reserved tokens. The operations apply to compiler-known values rather than arbitrary streamed datasets.

[PR #167](https://github.com/edujbarrios/semauri/pull/167) · [Semantics](../32_LIST_WINDOWS.md)

## Try the programs

```sh
semauri version
semauri check examples/list_boundaries.suri
semauri check examples/list_windows.suri
semauri run --allow console_write examples/list_boundaries.suri
semauri run --allow console_write examples/list_windows.suri
```

The expected version output is `Semauri 0.23.0`. Language reference and installation instructions: [language](../01_LANGUAGE.md), [installation](../00_INSTALLATION.md).

## Release distribution and limitations

The CI checks Rust tests and six native distributions (Windows, Linux and macOS on x86_64 and ARM64). GitHub Releases publishes six checked packages and `SHA256SUMS`. Confirm [the published release](https://github.com/edujbarrios/semauri/releases/tag/v0.23.0) before sharing links or packages.

This is not a runtime ML tensor processor; the ML domain still represents typed auditable **plans**, not implemented neural-network training. Typed user-defined functions, `map`, `filter` and runtime-dependent iteration remain roadmap work.
