# Semauri 0.67.0 — Interoperable Unicode string escapes

This release adds a standard, fixed-width Unicode spelling to Semauri's
ordinary string literals and a concise ASCII escape sequence.

## New language features

- `\uXXXX` decodes exactly four hexadecimal digits to a Unicode BMP scalar.
  For example, `\u0041` is `A` and `\u00E9` is `é`.
  This complements the existing `\u{HEX}` and `\UXXXXXXXX` forms.
- `\e` yields the ASCII escape character (U+001B), identical to `\x1B`.
- Invalid hex digits, short escapes, and surrogate code points (U+D800–U+DFFF)
  are rejected with source-aware `S104` diagnostics.

## Compatibility and tooling

- Both single- and double-quoted ordinary strings support the new escapes;
  raw strings and triple-quoted blocks remain literal.
- The formatter preserves the original escape spelling.
- VS Code highlighting, compiler regressions, a checked example and the
  [language guide](../language-guide.md) are updated.
- No new dependencies, runtime effects, or permission requirements.
- Six native release archives cover Linux, macOS and Windows (x86_64/ARM64),
  with SHA-256 checksums for verification.
