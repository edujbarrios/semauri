# Semauri 0.48.0

Semauri 0.48.0 expands its typed numeric language with three pure,
inspectable mathematical operations.

## Round to nearest

```text
assert (round of 2.49) is equal to 2.
assert (round of 2.5) is equal to 3.
assert (round of (minus 2.5)) is equal to (minus 3).
```

`round of NUMBER` chooses the nearest whole number. Halfway cases
round away from zero. Exact signed 64-bit inputs remain unchanged.
Finite float results become integers only inside the safe i64 range;
larger values remain floating point instead of saturating.
Invalid operand types raise `S427` and non-finite inputs `S428`.

## Truncate toward zero

```text
assert (truncate of 2.9) is equal to 2.
assert (truncate of (minus 2.9)) is equal to (minus 2).
assert (floor of (minus 2.9)) is equal to (minus 3).
```

`truncate of NUMBER` discards the fractional component toward zero,
distinct from floor for negative numbers. Values retain signed integer
precision; safe float bounds prevent lossy saturation. Invalid types
raise `S429`, and non-finite operands `S430`.

## Bounded factorials

```text
assert (factorial of 0) is equal to 1.
assert (factorial of 5) is equal to 120.
assert (factorial of 20) is equal to 2432902008176640000.
```

`factorial of NUMBER` calculates an exact integer result for finite,
integral operands between 0 and 20 inclusive (including integral
decimal values). Larger integers, negative values and fractions are
rejected with located `S432` diagnostics. Non-number inputs raise
`S431` during type checking.

## Compiler integration and compatibility

All three operators work with typed functions, list transformations,
optimizer folding, the effect-aware evaluator, canonical formatting
and VS Code syntax highlighting. Their names remain valid ordinary
identifiers unless directly followed by `of`. They are pure and
require no additional runtime capabilities.

The release includes runnable programs in `examples/`, type and
runtime regression tests, and updated README documentation.

## Distribution

GitHub Actions builds and publishes six packages: Linux, Windows
and macOS in x86_64 and ARM64 flavors, plus `SHA256SUMS` for verifying
downloaded archives.
