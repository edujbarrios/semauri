# Semauri 0.36.0

Semauri 0.36.0 adds strictly typed JSON decoding and safe JSON object
inspection while preserving Semauri's readable English syntax, immutable values,
explicit effects, and deterministic local execution.

## New language capabilities

### Typed JSON decoding

Use `decode json as TYPE from TEXT` for these six target types:

- `string`
- `number`
- `boolean`
- `strings` (`list<string>`)
- `numbers` (`list<number>`)
- `booleans` (`list<boolean>`)

All decoded values are statically typed. JSON must match the target exactly:
strings cannot silently become numbers, and a heterogeneous array cannot
silently become a homogeneous list. Invalid JSON and incompatible structures
produce located compiler/runtime diagnostics (`S396` and `S397`).

To limit resource consumption, the parser enforces a 1 MiB input limit and
10,000 list elements. Integer tokens outside the signed 64-bit range are
rejected before imprecise numeric conversion. Literal inputs may be evaluated
at compile time without compromising error handling.

### JSON object inspection

- `keys of json DOCUMENT` returns an alphabetically sorted `list<string>`
  of top-level object keys, including objects with non-scalar values.
- `has json key KEY in DOCUMENT` returns a typed `boolean`. Keys with JSON
  `null` values count as present.

Both operations require string operands, reject invalid or non-object documents,
and enforce the 1 MiB / 10,000-key safety limits. Diagnostics: `S398` and
`S399`.

## Example

```text
let values be decode json as numbers from "[12,25,33]".
assert sum of values is equal to 70.

let settings be "{\"active\":true,\"name\":\"demo\"}".
let names be keys of json settings.
assert length of names is equal to 2.
assert has json key "active" in settings.
assert not (has json key "missing" in settings).
```

The new expressions are pure and introduce no additional effect grants,
network traffic, or dependencies. The formatter, optimizer, VS Code grammar,
and executable examples have been updated.

## Installation

Download and extract the archive for your platform, put the `semauri`
executable on `PATH`, and run `semauri version`.

The release pipeline publishes Linux, macOS, and Windows distributions
for x86_64 and ARM64, along with `SHA256SUMS`.

## Compatibility and limitations

The new phrases are contextual; existing identifiers and domain operations
remain supported. JSON field values cannot yet be projected into records, and
Semauri does not yet provide arbitrary maps, HTTP client primitives, a package
manager, or full hosted AI-provider adapters. These limitations remain on the
development roadmap. See the root README for the canonical language guide.
