# Semauri 0.56.0 — Scientific computation and checked numeric operations

Semauri 0.56.0 adds typed, deterministic mathematical expressions to its native
Rust compiler, helping users implement numerical and educational AI algorithms
directly in `.suri` without a separate machine-learning library.

## Included pull requests

- [#291](https://github.com/edujbarrios/semauri/pull/291): `exp of`, `ln of`, `sin of`, `cos of`; finite-domain validation, type diagnostics, constant folding, tests and examples. Trigonometric arguments use radians.
- [#292](https://github.com/edujbarrios/semauri/pull/292): `power of BASE to EXPONENT`; exact checked integer powers and finite real fractional or negative powers, with domain/overflow diagnostics.
- [#293](https://github.com/edujbarrios/semauri/pull/293): `variance of` and `stdev of` for numeric lists; stable one-pass population statistics, finite-result checks, and tests.

## Runnable example

```text
let samples be a list of 0, 2, 4.
let spread be variance of samples.
let deviation be stdev of samples.
let squared be power of 3 to 2.
let growth be exp of 0.
assert squared is equal to 9.
assert growth is equal to 1.0.
assert spread is greater than 2.
assert deviation is greater than 1.
print "Scientific computation OK".
```

See `examples/scientific_math.suri`, `examples/power.suri`, and
`examples/statistics.suri`. All new operations are pure, typed, and permission-free.
Validation rejects nonnumeric arguments, undefined real domains, overflow, and
non-finite results rather than silently returning NaN or Infinity.

## Compatibility and boundaries

- Rust crate, lockfile, citation, README and release version: **0.56.0**;
  experimental Jupyter language version: **0.56**.
- No new runtime effect grants or external dependencies.
- **Semauri is not yet a general-purpose replacement for Python/Rust/JavaScript.**
  Mutable state, richer iteration, records/maps, errors, broad standard-library I/O,
  packages, provider adapters and a general model-training runtime remain priorities.
  The existing ML `fit/train` syntax models plans; it does not execute training.
- Release automation produces six platform archives (Windows, Linux and macOS on
  x86_64 and ARM64) and SHA256 checksums when workflows succeed.
