# Semauri 0.40.0

Semauri 0.40.0 expands safe, statically typed Unicode text manipulation in
natural English syntax. This release follows 0.39.0's scalar and code-point
conversion operations and preserves pure deterministic evaluation and explicit
effect permissions.

## New: Direct Unicode character indexing

Use `character at INDEX in TEXT` to retrieve a string containing the scalar
at a zero-based Unicode position. Indexing uses Unicode scalar values, not UTF-8
bytes or extended grapheme clusters.

```text
let text be "Aé🙂".
assert (character at 0 in text) is equal to "A".
assert (character at 1 in text) is equal to "é".
assert (character at 2 in text) is equal to "🙂".
```

- Requires a numeric index and string text (`S410`).
- Rejects non-integer, negative and out-of-range indices with `S411`.
- Shares evaluation and constant-folding semantics for valid literal indices.

## New: Literal substring removal

Use `remove all of NEEDLE from TEXT` to remove all non-overlapping literal
matches. The matching is case-sensitive, Unicode-aware, and treats search text
as a plain string, not a regular expression.

```text
let cleaned be remove all of "é" from "café café".
assert cleaned is equal to "caf caf".
let compact be remove all of "aa" from "aaaaa".
assert compact is equal to "a".
```

- Both inputs must be strings (`S412`).
- Empty needles are invalid and produce `S413` with source location.
- Missing matches return the original string; valid literals are constant-folded.
- The existing reserved `remove` domain action remains supported and is not
  converted into a general identifier.

## Quality and compatibility

Both operators have integrated parser, type-checker, runtime, optimizer,
formatter, runnable example, editor grammar where applicable, and Rust
integration test coverage. These are pure operations; no network or filesystem
permissions, external services, or new dependencies are introduced.

The release pipeline packages Semauri for Linux, macOS, and Windows on ARM64
and x86_64, plus `SHA256SUMS`. Select the correct platform archive, extract
the compiler executable, put it on your `PATH`, and check its version.

Semauri still counts Unicode scalar values rather than extended grapheme
clusters. Regex-based replacement and locale-specific case folding are not
provided by these new expressions.
