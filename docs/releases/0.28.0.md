# Semauri 0.28.0 — Typed List Reductions and Short-Circuit Quantifiers

Version 0.28.0 expands Semauri's statically typed, pure, compiler-known collection processing.

## Seeded reductions

```sema
let values be a list of 2, 4, 6.
let total be reduce every n in values starting acc as 0 to (acc plus n).
assert total is equal to 12.
```

`reduce every ITEM in LIST starting ACC as SEED to BODY` evaluates the concrete input and seed once. Each step introduces lexically scoped, immutable item and accumulator bindings; the expression body must return the seed type. Empty typed lists return the seed unchanged. Supports numbers, strings, booleans, nested lists, and earlier-declared pure typed functions. Type errors are S379 for non-lists, S380 for a mismatched accumulator, S381 for impure bodies, and S250 for malformed syntax.

## Boolean quantifiers

```sema
let values be a list of 2, 4, 6.
let any_large be any every n in values if (n is greater than 5).
let all_even be all every n in values if ((n modulo 2) is equal to 0).
assert any_large is equal to true.
assert all_even is equal to true.
```

Both expressions type-check the list and scoped predicate before evaluation, and return a Boolean result without materializing an intermediate filtered list. `any every` stops on the first true element; `all every` stops on the first false. For empty typed lists, `any every` returns false and `all every` returns true. Non-list inputs produce S365, non-Boolean predicates produce S366. Existing prefix forms `any of` and `all of` remain available.

## Try it

```sh
semauri version
semauri check examples/reduce_every.sema
semauri check examples/quantified_predicates.sema
semauri run --allow console_write examples/reduce_every.sema
semauri run --allow console_write examples/quantified_predicates.sema
```

The native distribution workflow publishes Windows, Linux and macOS builds for x86_64 and ARM64, along with SHA256SUMS, after all build and test gates pass. Verify the [published v0.28.0 GitHub Release](https://github.com/edujbarrios/semauri/releases/tag/v0.28.0) before sharing binaries.

**Limitations:** These operations execute only over concrete compiler-known lists. They do not execute arbitrary dynamic streams, remote ML datasets, tensors, or model training. No new effects or capabilities have been granted.
