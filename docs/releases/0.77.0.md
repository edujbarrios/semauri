# Semauri 0.77.0 — Run and print without extra flags

Semauri's simplest program now works from the terminal immediately:

```text
print "Hello, Semauri!".
```

```sh
semauri run hello.suri
# Or simply:
semauri hello.suri
```

## What's new

- **Console output by default:** `print` no longer requires
  `--allow console_write` in normal execution.
- **Direct .suri execution:** `semauri FILE.suri` works as a shorthand
  for `semauri run FILE.suri`; options such as `--allow` work with either.
- **Easy testing:** `semauri test PATH` and `semauri verify PROJECT`
  allow console prints without `--allow-console`.
- **Explicit strict mode:** `--deny-console` disables printing for
  `run`, `test` and `verify`. Even a legacy explicit console grant
  does not override the denial.
- **Clearer documentation:** a shorter README focused on installation,
  language composition, actual code and its core features.
- **Better regression coverage:** end-to-end tests for defaults, the new
  shortcut, backwards compatibility, strict behavior and permission isolation.

## Safety and compatibility

Only the terminal-output capability changed its default. Filesystem,
network, AI, configuration and secure random effects still need explicit
grants (for example `--allow secure_random`).

Old commands using `--allow console_write` or `--allow-console` remain
supported. `semauri check FILE --allow-none` continues to enforce a strict
policy when requested, and all source type checks remain unchanged.

No new runtime dependencies.

Run `cargo test --all-targets` and `semauri check examples/quickstart.suri`
when building from source.
