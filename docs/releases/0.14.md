# Semauri 0.14.0

Semauri 0.14 completes the native compiler migration and makes the Rust implementation the only maintained implementation in the repository.

## Highlights

- Native Rust compiler and CLI for the full current language pipeline.
- Typed lexer/parser/AST/HIR, optimization, effects, lowering, multi-domain IR and runtime planning.
- Console, Web, Structured Data, Filesystem and ML semantic domains.
- Executable `Print VALUE.` programs with capability-gated console output.
- External `DomainSpec` / `DomainRegistry` extension API.
- External `BackendRegistry` renderers.
- Generic declarative artifacts for third-party domains.
- Explicit action-collision handling through `Within <domain>:` scopes.
- Rust integration coverage for language, compiler, ML and extension contracts.
- Native release packages for Linux, macOS and Windows on x86_64 and arm64.

## Distribution

Published packages contain the native `semauri` executable plus license, notice, README and package metadata. End users do not need a compiler toolchain or language runtime installed.

The quick installers continue to verify release checksums and select the correct package for the current operating system and architecture.
