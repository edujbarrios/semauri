# Semauri 0.61.0 — Natural membership and conversational control flow

The Rust-based, statically typed Semauri language adds expressive Python-like syntax while retaining its natural-language style.

- `item in collection` and `item not in collection`, plus `item is in collection` and `item is not in collection`, for typed lists and Unicode substring search.
- `elif CONDITION:` / `elif CONDITION then:` as aliases for `otherwise if`.
- Optional English `then:` in `if` / `when` conditional statements.
- Optional English `do:` in `for` loops.
- Compile-time membership typing and existing `S344` errors remain enforced; no new I/O capabilities or dependencies.
- New regression tests, executable example, VS Code syntax highlighting, notebook completions/help, and refreshed docs.

See `examples/natural_syntax.suri` and `docs/language-guide.md`.
