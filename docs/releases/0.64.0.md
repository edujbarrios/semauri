# Semauri 0.64.0 — Natural Boolean, membership and divisibility syntax

Semauri continues toward readable English-like programming with explicitly
checked types, Rust-backed evaluation and opt-in effect capabilities.

## Natural Boolean tests

- `flag is true` / `flag is false`
- `flag is not true` / `flag is not false`
- Strict Boolean checking: no implicit conversion from numbers or strings.

## Expressive membership

- `item is one of values` / `item is not one of values`
- The same typed list membership and Unicode substring checks already used by
  `in` and `not in`, preserving `S344` on incompatible operands.

## Divisibility and multiples

- `number is divisible by divisor` / `is not divisible by divisor`
- `number is a multiple of divisor` / `is not a multiple of divisor`
- Desugared through typed `modulo` and equality/inequality; zero divisors
  preserve diagnostic `S317`. Fractional numbers follow floating-point
  remainder semantics rather than exact-decimal arithmetic.

## Improved numerical correctness

- Native exact i64 remainder in both constant folding and runtime, without
  rounding through binary64. Preserves odd/even results for numbers beyond
  2^53 and handles the signed i64 minimum modulo -1 without overflow.

## Developer experience

- Rust regression tests, executable examples, strict error cases and
  backward-compatibility coverage.
- Updated documentation, source formatter, VS Code syntax highlighting,
  Jupyter completion and offline help.
- No new runtime dependencies or effect permissions.
