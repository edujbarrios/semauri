# Semauri 0.21.0 — Typed Boolean Logic and Numerical Medians

Semauri is a statically typed programming language with an independent Rust compiler, structured-English source syntax, source-located diagnostics and explicit runtime effect permissions. Version 0.21.0 extends its pure core-language data processing.

## Boolean list reductions

```sema
let checks be a list of true, false, true.
let some_pass be any of checks.
let every_pass be all of checks.
assert some_pass is equal to true.
assert every_pass is equal to false.
```

`any of` and `all of` accept `list<boolean>` and return `boolean`. They do not mutate their input or grant any execution capabilities. Wrong operand types produce `S356`. In the current parser, list literals must have at least one member; if future runtime sources produce an empty list, the identities are `false` for any and `true` for all.

[PR #160](https://github.com/edujbarrios/semauri/pull/160) · [Specification](../27_BOOLEAN_REDUCTIONS.md)

## Typed numerical median

```sema
let measurements be a list of 10, 2, 8, 4.
let center be median of measurements.
assert center is equal to 6.
print center.
```

`median of` accepts a concrete finite `list<number>`. An odd list returns its sorted middle member; even lists return the midpoint between the two middle values. Integer-only comparisons remain exact, even beyond `2^53`, and even integer midpoints use widened `i128` summation. Fractional or mixed numeric results use floating-point rounding. Non-numeric operands produce `S353`; empty/non-finite data are guarded by `S357`.

Existing unary `minus` operations now preserve exact `i64` values rather than converting through `f64`, in both evaluation and compile-time constant folding; impossible negations have diagnostic `S358`.

[PR #161](https://github.com/edujbarrios/semauri/pull/161) · [Specification](../28_MEDIAN.md)

## Compatibility

`any`, `all` and `median` are newly reserved keywords; existing programs using them as unquoted bare variable identifiers need renaming. Language commands remain case-insensitive with canonical lowercase formatting. These operations apply to core-language lists, **not** external model tensors or runtime ML data handles. No training backend has been introduced.

## Run the examples

```sh
semauri version
semauri check examples/boolean_reductions.suri
semauri check examples/median.suri
semauri run --allow console_write examples/boolean_reductions.suri
semauri run --allow console_write examples/median.suri
```

Expected version string: `Semauri 0.21.0`. Installation and manual SHA256 verification instructions are in [the installation guide](../00_INSTALLATION.md).
