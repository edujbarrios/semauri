# Semauri v0.27.0 — Lazy Typed Conditionals and Bounded Lists

This release improves the expressiveness of Semauri's statically typed, immutable Rust-compiled core by allowing functions to **choose a typed value** and code to **construct repeated typed lists**.

## Conditional expressions

```sema
define function magnitude taking n as number to (if (n is less than 0) then (minus n) otherwise n).
let measurements be a list of minus 4, 1, 0, minus 8.
let magnitudes be map every x in measurements to (invoke magnitude to x).
print magnitudes.
```

Expected: `[4, 1, 0, 8]`. Both branches are statically typed and checked to return the same type, but only the selected branch executes. This prevents unused branch failures, such as division by zero. Nonnumeric boolean conditions fail with `S375`, and differing branch types produce `S376`. The existing `if:...end.` statement syntax remains unchanged.

[Conditional feature PR #178](https://github.com/edujbarrios/semauri/pull/178) · [Semantics](../39_CONDITIONAL_EXPRESSIONS.md)

## Typed bounded repetition

```sema
let scores be repeat 4 of 3.
let doubled be map every n in scores to (n times 2).
let nothing be repeat 0 of true.
print doubled.
```

Expected: `[6, 6, 6, 6]`. One element is evaluated once and copied to create a new `list<T>`. Lists (including nested lists) retain types and are never mutated. Counts must be signed integers from 0 through 10,000 inclusive; other numeric forms or out-of-range values receive `S378`, and nonnumeric count types `S377`. The word `repeat` stays contextual.

[Repeat feature PR #179](https://github.com/edujbarrios/semauri/pull/179) · [Semantics](../40_REPEAT_LISTS.md)

## Try the features

```sh
semauri version
semauri check examples/conditional_expressions.suri
semauri check examples/repeat_lists.suri
semauri run --allow console_write examples/conditional_expressions.suri
semauri run --allow console_write examples/repeat_lists.suri
```

These features apply to concrete compiler-known data, not live stream processing, tensors, or neural-network training. No new effects or permissions are granted.

After CI approval, the release workflow creates the native Windows, macOS and Linux archives for x86_64 and ARM64 with `SHA256SUMS`. Check [GitHub Release v0.27.0](https://github.com/edujbarrios/semauri/releases/tag/v0.27.0) for verified binaries.
