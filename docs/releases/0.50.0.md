# Semauri 0.50.0 — Exact cube roots, safe reciprocals, and integer digit counts

This release introduces three **typed, pure numeric expressions** in the
Semauri compiler. They work in `.suri` files, typed functions, list
transformations, the optimizer and compiler-inspection commands. They
introduce no new runtime permissions or Rust dependencies.

## New operators

| Expression | Result | Domain check |
| --- | --- | --- |
| `cbrt of NUMBER` | Exact integer for perfect integer cubes, otherwise a finite float | `S437` invalid type; `S438` non-finite input |
| `reciprocal of NUMBER` | Finite floating-point `1 / n` | `S439` invalid type; `S440` zero, non-finite input/result |
| `digits of NUMBER` | Exact integer decimal digit count, ignoring minus sign | `S441` invalid type; `S442` fraction or outside signed i64 domain |

In `digits of`, zero counts as one digit, and even the signed 64-bit
minimum is handled exactly. Finite integral decimal inputs are permitted
only if they fit in the signed 64-bit integer domain.

The new words remain usable as variable names except in the operator
phrases `cbrt of`, `reciprocal of`, and `digits of`.

## Example

```text
assert (cbrt of (minus 27)) is equal to (minus 3).
assert (reciprocal of 4) is equal to 0.25.
assert (digits of 9007199254740993) is equal to 16.
print cbrt of 125.
print reciprocal of 8.
print digits of (minus 123456).
```

Expected stdout:

```text
5
0.125
6
```

See `examples/numeric_cbrt.suri`,
`examples/numeric_reciprocal.suri`, and `examples/numeric_digits.suri`
for runnable, assertion-backed examples.

## Quality gates

Each new expression has parser/HIR, optimizer, evaluation, formatter,
editor highlighting, and integration tests. CI runs the Rust compiler
suite, example conformance, Jupyter kernel protocol integration and
six-platform release distribution builds (Linux, macOS, Windows on
x86_64 and ARM64).

The GitHub release includes native archives and their `SHA256SUMS`.
