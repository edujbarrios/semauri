# Semauri v0.31.0 — `.suri` source files

Semauri 0.31.0 replaces the `.sema` filename suffix with `.suri` to give the language a distinct, recognizable source extension.

## Migration

Rename every Semauri source file:

```text
hello.sema -> hello.suri
```

Then use the same CLI commands with the new filename:

```sh
semauri check hello.suri
semauri run --allow console_write hello.suri
semauri test path/to/tests
```

The `test` command now discovers `.suri` files recursively. `.sema` files are no longer discovered as Semauri test files.

## Complete repository migration

- All 43 runnable examples now use `.suri`.
- All 22 English and Spanish course programs and their guide links now use `.suri`.
- Rust test fixtures, conformance checks, native-package smoke tests and release scripts use `.suri`.
- The full Rust test suite validates the migrated examples and both learning courses.

## Why `.suri`

The suffix is short, comes directly from the Semauri name, and was not found in the IANA media-type registry or the current GitHub Linguist extension catalog during the v0.31.0 migration. This is a practical collision check rather than a claim that any filename suffix can be proven globally unused. In contrast, IANA already registers the unrelated `application/vnd.sema` media type.
