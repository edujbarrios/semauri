# Semauri 0.16.0 — Learn to Code

Semauri 0.16.0 introduces a complete entry point for beginners while shipping the most recent language improvements.

## What's new

- **[Learn to Code](../../learn_to_code/README.md):** 11 short lessons in Spanish. Each has an introduction, working `.sema` program, expected results and a challenge.
- The course ships not only in the source repository and GitHub's source archives, but also in **all six native binaries archives**.
- More expressive conditionals: `Otherwise if`, `Else if` and `Unless`.
- Unicode escapes such as `\u{1F30D}` in double-quoted strings.
- Cleaner repository navigation for learners, users and contributors.
- CI contract tests prevent course examples from drifting away from the language.

## Start in 30 seconds

From the root of the repository or the extracted release package (with `bin/semauri` on PATH):

```sh
semauri version
semauri check learn_to_code/01_hola_mundo/main.sema
semauri run --allow console_write learn_to_code/01_hola_mundo/main.sema
```

For the generated HTML example:

```sh
semauri build learn_to_code/10_crea_una_web/main.sema
```

## Compatibility and security

No breaking grammar changes are intended. The language remains experimental. Compilation never executes side effects; console output still requires the `console_write` capability. The educational examples perform no filesystem or network side effects.

## Distribution

Native binaries: Linux/macOS/Windows on x86_64 and ARM64. Download the matching package from the GitHub Release and verify `SHA256SUMS`. The installed compiler and the bundled tutorials are version-matched.
