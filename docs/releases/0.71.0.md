# Semauri 0.71.0 — Numerical series and model evaluation

Semauri v0.71.0 extends natural-language-inspired numerical programming with
**typed running computations**, **sequential differences**, and **prediction
error metrics**. It builds on v0.70.0's checked `difference between` expressions.

## Cumulative and sequential calculations

Use readable expressions to analyze a sequence without writing a loop:

```suri
let readings be a list of 3, 5, 2, 6.
let totals be running total of readings.
let averages be running average of readings.
let minima be running minimum of readings.
let maxima be cumulative maximum of readings.
let products be running product of readings.
let changes be adjacent differences of readings.

assert totals is equal to (a list of 3, 8, 10, 16).
assert (averages at 3) is equal to 4.
assert minima is equal to (a list of 3, 3, 2, 2).
assert maxima is equal to (a list of 3, 5, 5, 6).
assert products is equal to (a list of 3, 15, 30, 180).
assert changes is equal to (a list of 2, (minus 3), 4).
```

Supported alternatives include `running sum` / `cumulative sum`,
`cumulative average`, `cumulative minimum`, `cumulative maximum`,
`cumulative product`, `running min/max`, and `successive differences`.

These operations process typed numeric lists in linear time. All are pure,
evaluate the source list once, and return an empty list for empty input.
Checked signed 64-bit accumulation and products retain integer precision.
Prefix extrema compare large integers exactly; decimals require finite results.

## Error metrics for predictive models

Given signed residuals (observed minus predicted), common error and bias
statistics are expressible directly:

```suri
let observed be a list of 3, 6, 5.
let predicted be a list of 1, 9, 4.
let residuals be zip every actual in observed with estimate in predicted
  to (difference between actual and estimate).

assert (mae of residuals) is equal to 2.
assert (mse of residuals) is equal to (14 divided by 3).
assert (rmse of residuals) is equal to (sqrt of (14 divided by 3)).
assert (mbe of residuals) is equal to 0.
```

The same operators support natural-language long forms:
- `mean absolute error of ERRORS`, `mean magnitude of ERRORS`,
  `sum of magnitudes of ERRORS`, and `max magnitude of ERRORS`
- `mean squared error of ERRORS`, `mean square of ERRORS`,
  `sum of squares of ERRORS`
- `root mean squared error of ERRORS`, `root mean square of ERRORS`
- `mean bias error of ERRORS` and `mean error of ERRORS`

**MAE** measures average absolute error; **MSE** averages squared error;
**RMSE** takes the square root of MSE; **MBE** preserves signed errors
to measure bias. All take already-computed residual lists, not two separate
series. Inputs are checked and arithmetic errors remain source-located.

## Documentation, compatibility and distribution

- Four new runnable `.suri` examples: `running_statistics.suri`,
  `squared_statistics.suri`, `absolute_error_statistics.suri`,
  and `model_error_metrics.suri`.
- Regression tests for exact large integers, decimals, empty and invalid
  lists, overflow, formatter round trips, typed AST/HIR, and effect analysis.
- Updated language guide, Jupyter completions/help, and VS Code highlighting.
- No new Rust dependencies or runtime capabilities. Existing permissions
  and source compatibility are unchanged; the new phrases remain contextual.

Prebuilt archives are provided for **Linux (x86_64, ARM64)**,
**macOS (Intel, Apple Silicon)** and **Windows (x86_64, ARM64)**,
alongside `SHA256SUMS` for integrity verification.

Install using the commands in the repository
[README](https://github.com/edujbarrios/semauri#1-install), or visit
[the GitHub releases page](https://github.com/edujbarrios/semauri/releases).
