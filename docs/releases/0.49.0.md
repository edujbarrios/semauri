# Semauri 0.49.0 — Native Jupyter integration and typed mathematics

Semauri now includes an **experimental official kernel** for Jupyter
Notebook and JupyterLab, maintained alongside the Rust compiler, plus
two typed expressions for exact 64-bit numerical work.

## Use Semauri in a Jupyter notebook

Install the native Semauri CLI on your `PATH`, clone the repository, then:

```sh
python3 -m pip install -e ./integrations/jupyter
semauri-jupyter-install --user
python3 -m pip install jupyterlab
jupyter lab
```

Create a notebook or open
`integrations/jupyter/examples/hello_semauri.ipynb`. Select the
**Semauri** kernel and run:

```text
let numbers be range from 1 to 5.
let squares be map every n in numbers to (square of n).
print squares.
```

Expected output:

```text
[1, 4, 9, 16, 25]
```

The first nonblank line of a cell can contain `%%check`, `%%explain`,
`%%explain --json`, `%%effects` or `%%plan`. They are notebook
directives, not part of Semauri syntax. The original
`semauri explain` text and JSON contracts are unchanged.

**Important:** cells are isolated full programs. State/variables do not
carry across cells. Persistent notebook sessions would require a new,
proper incremental compiler execution protocol: silently replaying earlier
cells could repeat filesystem or AI side effects.

The kernel permits only `console_write` by default. Additional effects
must be granted deliberately via `SEMAURI_ALLOW_EFFECTS` when launching
Jupyter. Use `SEMAURI_BINARY` for a non-standard executable location.
The kernel has a default cell timeout and removes temporary source files.
This feature requires Python/ipykernel for Jupyter transport, but the
Semauri compiler itself stays in Rust. No anywidget dependency is required.

## Checked numeric cube

```text
assert (cube of 4) is equal to 64.
assert (cube of (minus 2)) is equal to (minus 8).
```

`cube of NUMBER` preserves integer precision across signed 64-bit values,
refuses overflow with S434, and rejects non-number operands with S433.
Finite floating-point operands are supported. The word `cube` remains
an ordinary identifier outside the contextual `of` expression.

## Deterministic primality

```text
assert prime of 97.
assert not (prime of 561).
assert not (prime of 1).
```

`prime of NUMBER` is a pure, typed Boolean expression for signed 64-bit
integer inputs and representable integral decimal values. It uses exact
modular multiplication and deterministic 64-bit Miller–Rabin witnesses,
rather than unsafe floating-point approximations. Wrong operand types
raise S435; fractional or out-of-range decimals raise S436.

## Quality gates and distributions

Jupyter tests include a real wire-protocol integration test against the
Rust CLI, and numeric regression tests exercise optimizer, type checker,
formatter and evaluator. GitHub Actions builds native archives for Linux,
macOS and Windows on x86_64 and ARM64, plus a SHA256SUMS file.
