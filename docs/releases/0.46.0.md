# Semauri 0.46.0

Semauri 0.46.0 makes existing compiler explanations easier to discover and
adds structured explanation output for agents, editors and CI integrations.

## Understand the compiler without executing

`semauri check FILE` validates the program. `semauri explain FILE`
analyzes the typed program, lowers it to semantic artifacts and runtime
plans, and describes the decisions made. Neither command executes
application effects or builds artifacts.

For example, `examples/explain_walkthrough.suri` contains:

```text
within web:
  create a web called Example.
  add a button called Start.
end.
```

```sh
semauri check examples/explain_walkthrough.suri
semauri explain examples/explain_walkthrough.suri
```

The first command prints `OK`. The second prints:

```text
1. Entered semantic domain scope 'web'.
2. 'web' resolved to an HTML web document (default web backend).
3. Title explicitly set to 'Example'.
4. Added button 'Start' as button-1.
```

The included Rust test pins that exact text output so documentation
cannot silently drift when Semauri's explanation logic changes.

## JSON explanations for agents and tools

```sh
semauri explain examples/explain_walkthrough.suri --json
```

The result is a JSON object containing `ok: true`, `status: 0`, and
an ordered `explanations` array with the same four explanation strings
(without their numeric prefixes). On source errors, JSON mode provides
source-aware `diagnostics`, preserving the familiar CLI error status.

The existing text explanation format remains the default.
Both formats perform semantic analysis only and do not grant runtime
permissions or perform execution. Use `semauri effects FILE` and
`semauri plan FILE` for separate capability and runtime inspections.

## Compatibility and distribution

The `.suri` syntax, type system, execution model and runtime permissions
are unchanged. Existing `check`, `explain`, `hir`, `effects` and
`plan` calls remain backward compatible.

Release builds target Linux, Windows and macOS for x86_64 and ARM64
and include `SHA256SUMS` for verifying downloaded archives.
