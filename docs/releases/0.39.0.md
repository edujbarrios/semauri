# Semauri 0.39.0

Semauri 0.39.0 adds safe, statically typed Unicode scalar conversion to the
language's natural English syntax. This release follows 0.38.0's RFC 6901
JSON pointer navigation, and preserves deterministic compilation and explicit
effect permissions.

## New language expressions

- `characters of TEXT` converts a string into a typed `list<string>`
  of individual Unicode scalar values.
- `codepoints of TEXT` converts a string into a typed `list<number>`
  containing each scalar's numeric Unicode code point.
- `codepoint of TEXT` reads the numeric Unicode scalar from a string
  containing exactly one scalar.
- `character from NUMBER` constructs a single-character string from an
  exact integer Unicode scalar value.

## Example

```text
let letters be characters of "Aé🙂".
let numeric_values be codepoints of "Aé🙂".
assert length of letters is equal to 3.
assert (numeric_values at 1) is equal to 233.

let emoji be character from 128578.
assert codepoint of emoji is equal to 128578.
```

These operations follow Unicode scalar values (not UTF-8 byte offsets or
extended grapheme clusters). They support emoji, accented text, NUL, and other
valid Unicode scalars.

## Safety, compatibility, and diagnostics

- Operand types are checked statically; mismatches report `S408`.
- Invalid or out-of-range code points, UTF-16 surrogate values, decimal
  numbers, empty or multi-scalar input to `codepoint of`, and text longer
  than 10,000 Unicode scalars for list conversion report `S409`.
- The implementation is pure and shared between the optimizer and runtime,
  so valid literals can be folded without suppressing invalid-value errors.
- The new expression words are contextual; ordinary identifiers and existing
  language constructs remain compatible.
- No new packages, network effects, or filesystem permissions are required.

The compiler, static types, evaluator, optimizer, formatter, VS Code grammar,
runnable example, and Rust regression tests have all been updated.

## Download and verify

The release workflow produces Semauri archives for Linux, macOS, and Windows,
each on x86_64 and ARM64. Extract the matching archive, add the executable
to your `PATH`, and verify the version from the CLI.

Download `SHA256SUMS` alongside the release archive to verify integrity.
For previous features, canonical language syntax, and limitations, see
`README.md` and `CHANGELOG.md`.

Known limitations: character conversions are Unicode-scalar based; full
grapheme cluster segmentation and locale-aware collation are not provided.
