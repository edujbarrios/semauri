# Semauri 0.47.0

Semauri 0.47.0 enhances its statically typed, readable numeric
expressions with safe squares, square roots, and exact Boolean parity.

## Checked squares

```text
assert (square of (minus 5)) is equal to 25.
let numbers be a list of 1, 2, 3.
let squares be map every n in numbers to (square of n).
assert (squares at 2) is equal to 9.
```

Integer arithmetic is checked and exact throughout signed 64-bit range.
`square of 3037000500` reports an S422 overflow instead of wrapping;
non-number inputs report S421 during type checking. Finite decimals
are supported; non-finite decimal results are rejected.

## Typed square roots

```text
assert (sqrt of 81) is equal to 9.
assert (sqrt of (square of 12)) is equal to 12.
let root_two be sqrt of 2.
assert root_two is greater than 1.
assert root_two is less than 2.
```

Exact positive integer squares yield exact integer roots even for large
i64 input values. Other roots produce finite floating-point numbers.
Negative or non-finite roots produce S424; wrong types produce S423.

## Typed parity predicates

```text
assert even of 0.
assert odd of (minus 3).
assert even of 9223372036854775806.
let checks be map every n in (a list of 1, 2, 3) to (odd of n).
assert (checks at 0).
```

`even of NUMBER` and `odd of NUMBER` yield Boolean values. Signed
integers retain precise parity without floating-point coercion.
Integral finite decimal values are supported within the signed 64-bit
range. Non-integral, out-of-range or non-finite decimal values report
S426; non-number values report S425.

## Compatibility, tests and platforms

`square`, `sqrt`, `even` and `odd` remain usable as variable names:
the operators are recognized only when followed by `of`. All operations
are pure, constant-foldable and work in functions and list transformations.
The release includes executable examples, Rust regression tests and VS
Code syntax highlighting.

GitHub Actions builds native packages for Linux, macOS and Windows on
x86_64 and ARM64 with SHA256SUMS checksums.
