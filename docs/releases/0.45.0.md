# Semauri 0.45.0

Semauri 0.45.0 adds three pure, statically typed numeric expressions to
the language. They work in normal programs, defined functions, list
transformations, optimizer passes, and the existing effect-aware evaluator.

## Sign classification

```text
let measurements be a list of minus 3, 0, 2.75.
let directions be map every n in measurements to (sign of n).
assert (directions at 0) is equal to (minus 1).
assert (directions at 1) is equal to 0.
assert (directions at 2) is equal to 1.
```

`sign of NUMBER` produces numeric integer -1, 0, or 1. Signed zero
maps to zero; very large and minimum signed 64-bit integers remain exact.

## Numeric rounding

```text
assert (floor of 2.8) is equal to 2.
assert (ceiling of 2.2) is equal to 3.
assert (floor of (minus 2.2)) is equal to (minus 3).
assert (ceiling of (minus 2.8)) is equal to (minus 2).
```

`floor of NUMBER` rounds toward negative infinity;
`ceiling of NUMBER` rounds toward positive infinity.
Exact integers stay integers, preserving full 64-bit precision,
while finite floating-point numbers stay floating point after rounding.
No silent integer conversion takes place.

## Typing and compatibility

All expressions require numeric operands. The located diagnostics are
`S417` for invalid sign operands and `S419` for invalid rounding
operands. Evaluating non-finite numeric values produces `S418`
(sign) or `S420` (rounding) instead of silently propagating them.
The optimizer and runtime share numeric helpers to avoid mismatched results.

These are contextual operators: ordinary variables named `sign`,
`floor`, or `ceiling` continue to work whenever the name is not
followed by `of`. No existing grammar, types, permissions, or effect
policies are removed or relaxed.

## Editor support and distribution

The included TextMate grammar for VS Code recognizes the new operations,
and the repository has runnable `examples/numeric_sign.suri` and
`examples/numeric_rounding.suri` plus Rust regression coverage.

GitHub Actions builds native releases for Linux, macOS and Windows
(x86_64 and ARM64), with a `SHA256SUMS` file for asset verification.
