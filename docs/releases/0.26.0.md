# Semauri v0.26.0 — Multi-Parameter Functions and Precise Numeric Extrema

Semauri 0.26.0 expands pure user-defined functions and improves numeric correctness in the Rust compiler. The release is fully backward compatible with supported Semauri 0.25.0 function-call syntax.

## Functions with 1–16 typed parameters

```sema
define function weighted taking score as number, weight as number, bias as number to ((score times weight) plus bias).
let readings be range from 1 to 4.
let results be map every n in readings to (invoke weighted to (n, 2, 3)).
print results.
```

Expected: `[5, 7, 9, 11]`.

The compiler checks argument count and type and infers the function result type. New tuples `invoke NAME to (EXPR1, EXPR2, ...)` work together with the pre-existing one-parameter `invoke NAME to PRIMARY` and parenthesized single expressions, including a single list-valued argument. Parameters are immutable, bound only after the arguments are evaluated in order, and do not escape the function invocation frame.

Error `S374` is raised for an incorrect argument count, `S370` for a mismatched parameter type and `S311` for duplicate parameter names. Recursive calls, dynamic dispatch, forward references and functions with side effects are not supported. Functions must be declared at top level before use, and only operate on compiler-known data.

[Feature PR #175](https://github.com/edujbarrios/semauri/pull/175) · [Complete function semantics](../37_MULTI_PARAMETER_FUNCTIONS.md)

## Exact minimum/maximum with mixed numbers

```sema
let readings be a list of 9007199254740992.0, 9007199254740993.
print minimum of readings.
print maximum of readings.
```

The first value is the binary64 decimal representation of `2^53`, the second is the exact i64 integer `2^53+1`. Previously extrema could round the integer to f64 during comparison and incorrectly choose an element on a tie. The implementation now reuses the transitive comparator shared by `sorted of` and `median of`. Source element type is preserved for the returned extremum.

[Correctness PR #176](https://github.com/edujbarrios/semauri/pull/176) · [Precision specification](../38_EXACT_MIXED_EXTREMA.md)

## Run new examples

```sh
semauri version
semauri check examples/multi_parameter_functions.sema
semauri run --allow console_write examples/multi_parameter_functions.sema
```

The release CI runs Rust tests and builds native packages for Linux, macOS and Windows on ARM64 and x86_64, publishing six native packages and `SHA256SUMS` in the [v0.26.0 GitHub Release](https://github.com/edujbarrios/semauri/releases/tag/v0.26.0).

**Scope:** The language's ML domain provides typed audit and execution plans, but no live neural model training, tensors, or arbitrary runtime execution. Rust compiler checks and native platform release gates must pass before announcing this version.
