# Semauri 0.57.0 — More reliable literals and notebook development

Semauri 0.57.0 improves text literals, numeric safety and the development workflow for notebook users without granting any new effects.

## Language features

- Ordinary quoted strings accept `\\a` for ASCII bell (U+0007) and `\\v` for vertical tab (U+000B). Both single and double quote styles work. Raw and triple-quoted strings keep their literal backslashes.
- The formatter preserves the source spelling of escapes, and VS Code highlights both sequences.
- Floating-to-integer normalization no longer converts the floating value 2^63 to a saturated signed 64-bit integer; it remains a floating-point number. Existing negative and positive integer operations remain checked.

```text
let separator be "\\v".
let alert be '\\a'.
assert separator is equal to "\\u{000B}".
assert alert is equal to "\\u{0007}".
print "Semauri 0.57.0".
```

## Jupyter improvements

- Completion suggests bindings and function names declared earlier in the **same cell**, alongside language keywords and scientific operators. It does not replay previous cells.
- Shift+Tab inspection explains common keywords and notebook directives without invoking the compiler.
- `%%audit` invokes the existing read-only compiler audit from a notebook cell, with no additional permissions.

```text
%%audit
let points be a list of 1, 2, 3.
assert sum of points is equal to 6.
```

## Upgrade and compatibility

- Version 0.57.0 is reflected in `Cargo.toml`, `Cargo.lock`, `CITATION.cff`, `README.md` and the Jupyter language identifier (adapter package 0.2.0).
- Install binaries from the GitHub Release after the six-platform packaging workflow completes, or build with `cargo install --path . --locked`.
- No new external dependencies or implicit permissions.
- Semauri still lacks mutable sessions, general-purpose package management and a production backend for ML model training; notebook cells remain independent.
