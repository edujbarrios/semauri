# Semauri v0.29.0 — Zip, Partition and Flatten

The Rust compiler's statically typed pure list processing core now supports three additional immutable transformations. All operators retain the existing deterministic evaluation and capability model.

## Zip typed lists

```sema
let prices be a list of 10, 20, 30.
let quantities be a list of 2, 3, 4.
let totals be zip every price in prices with quantity in quantities to (price times quantity).
print totals.
```

Output: `[20, 60, 120]`. Zip evaluates both lists once and maps corresponding items from two potentially different element types, producing `list<U>` of the shorter length. Validation codes S383/S384. [PR #184](https://github.com/edujbarrios/semauri/pull/184) · [Details](../43_ZIP_EVERY.md).

## Partition typed lists into true/false buckets

```sema
let readings be a list of 3, 9, 1, 8.
let buckets be partition every n in readings if (n is greater than 5).
print buckets at 0.
print buckets at 1.
```

`partition every` returns `list<list<T>>`: matching values first, nonmatching values second, stable within each bucket. Empty typed sublists are permitted. Errors S365/S366 cover list/predicate types. [PR #185](https://github.com/edujbarrios/semauri/pull/185) · [Details](../44_PARTITION_EVERY.md).

## Flatten typed nested lists by one level

```sema
let nested be a list of (a list of 1, 2), (a list of 3, 4).
let merged be flatten of nested.
print merged.
```

Output: `[1, 2, 3, 4]`. A typed `list<list<T>>` becomes `list<T>`; no inputs are changed. Exactly one nesting layer is removed, including support for typed empty inner lists. Invalid operands raise S385. [PR #186](https://github.com/edujbarrios/semauri/pull/186) · [Details](../45_FLATTEN_LISTS.md).

## Reproduce

```sh
semauri version
semauri check examples/zip_every.suri
semauri check examples/partition_every.suri
semauri check examples/flatten_lists.suri
semauri run --allow console_write examples/zip_every.suri
semauri run --allow console_write examples/partition_every.suri
semauri run --allow console_write examples/flatten_lists.suri
```

The native distribution pipeline validates Linux, Windows and macOS for ARM64/x86_64 and publishes six platform packages and `SHA256SUMS`. [Release v0.29.0](https://github.com/edujbarrios/semauri/releases/tag/v0.29.0).

These concrete compiler-known list transformations do not stream ML datasets, implement tensors or execute model training. No new effect permissions are added.
