# Semauri 0.58.0 — Typed logarithms and inverse trigonometry

This release expands Semauri's native scientific number expressions, with full compiler support and explicit numerical safety checks.

## What's new

- `log2 of NUMBER` and `log10 of NUMBER` compute base-2 and base-10 logarithms.
- `asin of NUMBER`, `acos of NUMBER` and `atan of NUMBER` compute inverse trigonometric functions. All returned angles use **radians**.
- Logarithms reject zero and negative inputs. `asin` and `acos` reject inputs outside **[-1, 1]**. All five operations reject non-finite results and do not introduce filesystem, network, or AI effects.
- Typed HIR, optimizer, evaluator, formatter, AST serialization, VS Code grammar and Jupyter keyword support recognize these expressions.
- Domain checks produce located `S466` diagnostics; nonnumeric inputs produce `S465`.

## Example

```text
let bits be log2 of 8.
let magnitude be log10 of 100.
let angle be asin of 1.
assert bits is equal to 3.0.
assert magnitude is equal to 2.0.
assert angle is greater than 1.5.
assert angle is less than 1.6.
print "Scientific operators OK".
```

See `examples/scientific_math.suri` for additional list transformations and finite-domain examples.

## Upgrade and boundaries

- Rust crate, lockfile, citation, README, release docs and notebook language identifier all track **0.58.0**; Jupyter adapter package is **0.3.0**.
- Existing `.suri` syntax and explicit permission defaults remain unchanged.
- Distribution workflow creates six platform archives for Windows, Linux and macOS (x86_64/ARM64) plus `SHA256SUMS`, conditional on CI and packaging success.
- Semauri remains statically typed and lacks general mutable sessions, a broad package ecosystem and real model-training execution.
