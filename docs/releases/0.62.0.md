# Semauri v0.62.0 — Natural predicates and more typed functions

Released on November 3, 2026, following PRs #302, #303 and #304.

Semauri continues to improve its natural-language programming model while preserving static typing, explicit effect permissions, and predictable Rust compilation.

## New scientific math functions

- `asinh of NUMBER` — inverse hyperbolic sine.
- `acosh of NUMBER` — inverse hyperbolic cosine (NUMBER ≥ 1).
- `atanh of NUMBER` — inverse hyperbolic tangent (-1 < NUMBER < 1).
- `log1p of NUMBER` — numerically accurate natural logarithm of (1 + NUMBER), NUMBER > -1.
- `expm1 of NUMBER` — numerically accurate exp(NUMBER) - 1.

All require finite numbers and finite results, use existing S465/S466 diagnostics and support constant folding.

## Compact Python-like function names

The typed expressions `len of`, `abs of`, `mean of`, `min of`, `max of`, `strip of`, `upper of`, and `lower of` are aliases for existing Semauri operations. They retain the old syntax and type checking, rather than introducing Python's dynamic semantics.

## Natural-language predicates

- `value is empty` / `value is not empty` for strings and typed lists.
- `text is blank` / `text is not blank` for whitespace-only text.

These desugar through existing typed length, trim, equality and inequality operators.

## Quality and ecosystem

Includes Rust regression tests, executable examples, Jupyter completion/help, VS Code highlighting, updated reference documentation and the changelog.

No new runtime dependencies or execution capabilities are introduced.

See `examples/scientific_math.suri`, `examples/python_function_aliases.suri`, and `examples/natural_predicates.suri` for runnable examples.
