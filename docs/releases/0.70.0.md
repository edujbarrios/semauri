# Semauri 0.70.0 — Numeric differences

Semauri v0.70.0 adds natural-language expressions for signed differences
and two common error-metric building blocks.

## New language expressions

```text
let actual be 12.
let predicted be 9.
let residual be difference between actual and predicted.
let absolute_error be absolute difference between actual and predicted.
let squared_error be squared difference between actual and predicted.
assert residual is equal to 3.
assert absolute_error is equal to 3.
assert squared_error is equal to 9.
```

- `difference between A and B` computes the checked signed difference `A - B`.
- `absolute difference between A and B` returns the checked magnitude.
- `squared difference between A and B` returns the checked square.

The compiler reuses existing arithmetic HIR/runtime operators with
strict numeric typing and overflow checks. This release also corrects
the shared subtraction path to keep exact signed 64-bit integers instead
of converting them through f64; out-of-range or non-finite subtraction
results report S470. Constant folding shares the checked computation. No operands are duplicated;
pure constant folding, effect analysis and runtime behavior remain aligned.
Parenthesize non-atomic operands, such as `(A plus 1)`.

## Tooling, testing and distribution

- Add positive, negative, exact-integer and decimal cases; type,
  overflow and malformed-phrase checks; optimizer, effects and formatter
  tests; and a runnable example.
- Update the language guide, Jupyter offline help/completions and
  VS Code syntax highlighting.
- Preserve existing language syntax and capabilities. No dependencies
  or new effects. CI and six-platform release packaging remain in place.
