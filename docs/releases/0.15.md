# Semauri 0.15.0

Semauri 0.15 improves source-code readability, numeric expressiveness, and lexical error handling without changing the deterministic semantics of existing valid programs.

## Highlights

- `#` and `//` line comments, plus nestable `/* ... */` multi-line comments.
- Decimal and scientific notation: `2.5e-3`, `1E+4`.
- Numeric digit separators: `1_000_000`, `2.5e-3`.
- Dedicated `S105` for unclosed block comments.
- Dedicated `S106` for invalid and overflowing numeric literals.

## Example

```text
// Compute using readable numbers.
Let distance be 1_200.5.
Let scale be 2.5e1.
/* The following expression uses
   the typed arithmetic semantics. */
Print distance plus scale.
```

## Distribution

The existing Rust-only release workflow packages and smoke-tests executables for Linux, macOS and Windows (x86_64 and arm64). Installers fetch the latest published GitHub Release and verify SHA-256 checksums.
