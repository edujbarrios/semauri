# Semauri 0.16.1 — Bilingual Learn to Code

Semauri 0.16.1 makes the complete **Learn to Code** course accessible in both **Spanish and English** and aligns the downloadable packages with the new layout.

## Highlights

- The [Learn to Code landing page](../../learn_to_code/README.md) now acts as a language selector.
- [Español](../../learn_to_code/es/README.md): the full original 11-lesson beginner curriculum, now under `learn_to_code/es/`.
- [English](../../learn_to_code/en/README.md): all 11 lessons translated, with independent example programs, sample outputs and exercises.
- CI validates lesson structure, source checks, console outputs and generated Web / JSON Schema for **both** languages.
- Native distribution archives ship both language trees and smoke-test the first program in each.

## Quick start

```sh
semauri check learn_to_code/en/01_hello_world/main.suri
semauri run --allow console_write learn_to_code/en/01_hello_world/main.suri
semauri check learn_to_code/es/01_hola_mundo/main.suri
semauri run --allow console_write learn_to_code/es/01_hola_mundo/main.suri
```

Running `semauri check` does not execute the program; actual console output requires explicit `console_write` authorization. No new runtime effects or breaking syntax changes are introduced in 0.16.1.

## Downloads

Native packages are built and smoke-tested for Linux, macOS and Windows (x86_64 and ARM64). Verify the archive using the accompanying `SHA256SUMS` file.
