# Semauri 0.18.0 — A Programming Language for Readable, Typed and Predictable Software

Semauri is a programming language with a native Rust compiler, readable structured-English syntax, static types, a deterministic compilation pipeline and effect-aware runtime operations. Version 0.18.0 expands the language and makes it significantly easier to start programming.

## Highlights

### New typed string expressions

```sema
let language be "Semauri".
let uppercase_name be uppercase of language.
let lowercase_name be lowercase of uppercase_name.

assert lowercase_name is equal to "semauri".
print uppercase_name.
```

- `uppercase of <string>` and `lowercase of <string>` now work in variables, assertions, printing and composed expressions.
- Inputs are type-checked (`S351` for non-strings). Constant string inputs are folded during optimization, and Unicode case mapping is handled consistently by the compiler and runtime.
- Expressions are pure: no new permissions, external services or dependencies.
- Unicode mapping is not locale-specific and may expand a character into multiple characters. See [string case expressions](../22_STRING_CASE.md).

Implemented in [PR #150](https://github.com/edujbarrios/semauri/pull/150).

### From installation to your first working program

A new [beginner's first-program guide](../23_FIRST_PROGRAM.md) explains how to:

1. Open PowerShell, macOS Terminal or a Linux terminal.
2. Install a native release using the official installer, or download an archive and verify its SHA-256 checksum manually.
3. Create a working folder and save a plain-text `.suri` file in Notepad, nano or another editor.
4. Run `semauri check`, inspect with `--dry-run`, then explicitly authorize `console_write` to execute.
5. Troubleshoot `PATH`, incorrect file extensions and effect-permission errors.

The installation guide is updated with reproducible, version-pinned commands. The English and Spanish learning courses remain available. Implemented in [PR #151](https://github.com/edujbarrios/semauri/pull/151).

### Clearer language identity and README

The project now leads with its core identity as a programming language and explains what programs can build and execute, rather than opening with disclaimers. The main README includes a three-step quick start and focused project messages:

> **A programming language for readable, typed and predictable software.**
>
> **Write clearly. Compile confidently. Build with intent.**

Detailed implementation scope is still documented honestly in the architecture and ML reference. Updated in [PR #152](https://github.com/edujbarrios/semauri/pull/152).

## Prior language capabilities retained from 0.17.0

- Typed bindings, arithmetic, booleans, immutable homogeneous lists, conditionals and static iteration.
- Typed `length of`, `contains`, zero-based list indexing with `at` and immutable list concatenation with `plus`.
- `assert` and `semauri test`, source-located diagnostics and lowercase formatting with `semauri fmt`.
- Domain backends for web, JSON Schema and selected authorized filesystem/console operations.
- Typed ML workflow plans, validated SSA dataflow graphs, declared dataset/model revisions and preflight provenance auditing.

## Compatibility and current scope

Existing capitalized and lowercase `.suri` programs remain accepted. User-defined typed functions and general runtime-dependent control flow are future work. Semauri's ML domain describes typed workflows; model training is not executed by the reference backend.

## Installation

Published archives target Linux, macOS and Windows, on x86_64 and ARM64. Use the [installation guide](../00_INSTALLATION.md) or [your first program tutorial](../23_FIRST_PROGRAM.md), and verify archive integrity against the release's `SHA256SUMS`.

```sh
semauri version
```

Expected: `Semauri 0.18.0`.
