# Semauri 0.37.0

Semauri 0.37.0 expands practical JSON interoperability and Unicode-aware text
processing without compromising the language's statically typed English syntax,
pure evaluation, or explicit effect permissions.

## New: Typed JSON object field extraction

Use `json TYPE at KEY in DOCUMENT` to extract a field from an object encoded
as JSON text. The six requested types are:

- `string`, `number`, and `boolean`
- `strings`, `numbers`, and `booleans` for homogeneous typed lists

Missing fields, JSON `null`, wrong element types, malformed objects,
out-of-range integers, and oversized input produce a source-aware diagnostic.
Both the key and document must be strings (`S400`); invalid extraction uses
`S401`. Field names remain exact and case sensitive. The 1 MiB document and
10,000-item limits apply.

```text
let document be "{\"name\":\"Ada\",\"score\":42,\"tags\":[\"rust\",\"compiler\"]}".
let score be json number at "score" in document.
let tags be json strings at "tags" in document.
assert score is greater than 40.
assert (tags at 1) is equal to "compiler".
```

This extends `json of`, `decode json as`, `keys of json`, and
`has json key` from previous releases. It does not add untyped maps or
mutable records.

## New: Unicode-aware substring searches

- `occurrences of NEEDLE in TEXT` counts non-overlapping occurrences,
  with a located `S403` error for an empty needle.
- `position of NEEDLE in TEXT` returns the zero-based Unicode scalar
  index of the first match, or `minus 1` when absent. The position of
  an empty string is zero.
- Both expressions return `number`, require two strings (`S402`),
  and are eligible for constant folding.

```text
let text be "café café".
assert occurrences of "café" in text is equal to 2.
assert position of "é" in text is equal to 3.
assert position of "missing" in text is equal to minus 1.
```

The substring search is case sensitive and counts Unicode scalar values,
not UTF-8 bytes or locale-aware grapheme clusters.

## Development and compatibility

The compiler parser, HIR typing, evaluator, optimizer, formatter, and VS Code
grammar have been updated together. New runnable examples and integration tests
cover Unicode input, numeric precision, invalid data, and contextual keywords.
These operations are pure, require no extra permissions, and introduce no new
third-party dependencies.

The release workflow builds packages for Linux, macOS and Windows on x86_64
and ARM64, and publishes `SHA256SUMS`. Download the archive for your platform,
extract it, and put the executable on `PATH`.

Known limitations: typed JSON extraction is top-level only; a complete records
system, general HTTP client, package management and hosted AI provider support
remain separate planned capabilities. See the root README for canonical syntax.
