# Semauri 0.17.0 — Lowercase Syntax, Typed Collections, and ML Workflow Analysis

Semauri 0.17.0 collects the language and compiler improvements since **v0.16.1**. It makes lowercase code canonical, improves the typed core language and assertion tooling, and introduces inspectable ML dependency graphs and reproducibility-declaration checks. **This is an experimental compiler release, not a full ML execution engine.**

## Quick start

```sema
let values be a list of 10, 20, 30.
assert values contains 20.
assert (values at 1) is equal to 20.
assert length of values is equal to 3.
print "Semauri 0.17.0".
```

```sh
semauri check example.suri
semauri fmt example.suri --check
semauri run --allow console_write example.suri
```

## New language and developer-tool features

- **Canonical lowercase source**: official `.suri` files use lowercase commands; old uppercase/mixed-case syntax remains valid. `semauri fmt FILE [--check | --write]` normalizes recognized commands while preserving quoted strings, identifiers, comments and source spacing. All 19 example files and 22 bilingual lessons were migrated with a CI guard. [#146](https://github.com/edujbarrios/semauri/pull/146) · [#147](https://github.com/edujbarrios/semauri/pull/147) · [#148](https://github.com/edujbarrios/semauri/pull/148)
- **Typed assertions**: `assert <boolean>.` fails at runtime with a source-located `S502` without requiring file/network permissions. [#137](https://github.com/edujbarrios/semauri/pull/137)
- **Assertion test runner**: `semauri test PATH` discovers and executes assertion suites with strict effect restrictions; optional console output requires `--allow-console`. [#140](https://github.com/edujbarrios/semauri/pull/140)
- **Typed collection expressions**: `length of`, `contains`, zero-based list indexing (`list at index`), and immutable same-type list concatenation (`plus`). [#138](https://github.com/edujbarrios/semauri/pull/138) · [#139](https://github.com/edujbarrios/semauri/pull/139) · [#141](https://github.com/edujbarrios/semauri/pull/141) · [#142](https://github.com/edujbarrios/semauri/pull/142)
- **Machine-readable diagnostics**: `check --json` reports structured compiler findings while the standard CLI remains human-readable. [#135](https://github.com/edujbarrios/semauri/pull/135)
- **Safer filesystem execution**: native `delete` refuses directory recursion, with preflight argument checks; `--cwd` is not a security sandbox. [#134](https://github.com/edujbarrios/semauri/pull/134)
- **Executable documentation contracts**: checked-in examples and course programs are tested in CI. [#136](https://github.com/edujbarrios/semauri/pull/136)

## ML engineering capabilities

- **Typed SSA dataflow graphs**: `semauri graph FILE` emits a deterministic JSON graph of runtime producer/consumer dependencies, effects and source locations and checks invalid references. [#143](https://github.com/edujbarrios/semauri/pull/143)
- **Revision-qualified inputs**: `source dataset "path" revision "id"` and `resolve model "name" revision "id"` attach declared versions to typed ML datasets and models. [#144](https://github.com/edujbarrios/semauri/pull/144)
- **CI reproducibility preflight**: `semauri audit FILE --strict` rejects missing revision declarations and unseeded direct training forms using machine-readable warning codes. [#145](https://github.com/edujbarrios/semauri/pull/145)

Example:

```sema
within ml:
  let dataset be source dataset "./images" revision "dataset-v3".
  let model be resolve model "resnet18" revision "weights-v2".
  let device be select device "cpu".
  let config be configure training for 3 epochs using optimizer "adamw" learning rate 0.0003 batch size 16 seed 42.
  let run be fit model using dataset on device with config.
end.
```

```sh
semauri graph examples/ml_versioned_inputs.suri
semauri audit examples/ml_versioned_inputs.suri --strict
```

**ML trust boundary:** plans do not download or verify model/dataset artifacts, run PyTorch, execute training, or guarantee deterministic results. A clean audit checks *declarations only*. Framework execution and artifact verification require independent backends.

## Compatibility

Lowercase is a **recommended source convention**, not an enforced change to existing programs. `Let`, `LET` and `let` continue to parse identically as language commands. The formatter does not rewrite user-defined names, output strings or labels, and it does not alter Rust API capitalization. Existing compiler and capability policies are preserved.

## Installation and archives

Six native distributions are built by the release workflow: Linux (x86_64, arm64), macOS (x86_64, arm64), Windows (x86_64, arm64). Each includes the compiler, examples, English and Spanish learning courses, and documentation. After release publication, verify the relevant downloaded archive using the accompanying `SHA256SUMS` before installation.

```sh
semauri version
```

Expected version: `Semauri 0.17.0`.
