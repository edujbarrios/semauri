# Semauri 0.53.0 — Citable software and more expressive text literals

Semauri 0.53.0 strengthens scholarly software attribution and extends the
statically typed, natural-language-inspired `.suri` language with additional
UTF-8 text literal conveniences. Existing programs, typed HIR, constant folding,
and the explicit capability model remain compatible.

## Included pull requests

- [#274](https://github.com/edujbarrios/semauri/pull/274): add versioned `CITATION.cff` with original creator attribution and a README citation guide, plus version-parity regression tests.
- [#275](https://github.com/edujbarrios/semauri/pull/275): add `\\0` (null), `\\b` (backspace), and `\\f` (form feed) string escapes for both supported quote styles, preserving source-aware diagnostics.
- [#276](https://github.com/edujbarrios/semauri/pull/276): add `r"..." ` and `r'...'` raw UTF-8 strings (also uppercase `R` prefix) that keep backslashes literally.
- [#277](https://github.com/edujbarrios/semauri/pull/277): extend VS Code/TextMate highlighting for raw strings and control escapes with regression tests.

## Language examples

```text
let windows_path be r'C:\Temp\logs'.
let literal_marker be r"\n".
let actual_newline be "\n".
let control_text be "a\0b\bc\fd".
assert literal_marker is equal to "\\n".
print windows_path.
```

Raw strings still require a closing matching quote, and do not allow literal
newlines. Ordinary strings retain their existing Unicode escapes, including
`\\u{HEX}`, along with the new control escapes. All features are additive.
