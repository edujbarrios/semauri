# Semauri v0.22.0 — Typed Sorting and Stable Deduplication

Semauri 0.22.0 extends the pure, statically typed list-processing core of its Rust language compiler, improving the expressiveness of reproducible data-transformation pipelines.

## Sorted typed lists

```sema
let scores be a list of 8, 3, 5, 1.
let ascending be sorted of scores.
assert (ascending at 0) is equal to 1.
assert (scores at 0) is equal to 8.
```

`sorted of` works on concrete `list<number>`, `list<string>` and `list<boolean>` values, returning a **new list of the same type**. Numeric order is ascending and exact across integer/decimal variants even past `2^53`; a newly shared, transitive comparator also improves `median of` with mixed large ints and floating-point values. Text uses case-sensitive Unicode scalar lexicographic order, not locale-aware collation; booleans put `false` before `true`. Stable sort preserves order among equal items. Other operand types and non-finite numeric data receive `S359`.

[Implementation PR #163](https://github.com/edujbarrios/semauri/pull/163) · [Semantics](../29_SORTED.md)

## Stable, typed distinct values

```sema
let repeated be a list of 3, 1, 3, 2, 1.
let unique be distinct of repeated.
let ordered_unique be sorted of unique.
assert length of ordered_unique is equal to 3.
print ordered_unique.
```

`distinct of` supports homogeneous `list<T>` and returns a new list preserving only the first occurrence of each value. Equality is the same as existing list membership and structural equality, including distinct storage variants for integers versus decimals. No mutation; type `list<T> -> list<T>`. Non-list operands are statically rejected with `S360`. Deduplication is currently quadratic on concrete lists; it is not a streaming external-data operation.

[Implementation PR #164](https://github.com/edujbarrios/semauri/pull/164) · [Semantics](../30_DISTINCT.md)

## Compatibility

- `sorted` and `distinct` are newly reserved words; rename any existing bare identifiers using them.
- Source keywords remain case-insensitive; canonical source remains lowercase.
- Both operations compile into deterministic, type-checked plans and evaluate concrete list values. They do not implement ML model training, external tensor computations or streaming execution.

## Try the examples

```sh
semauri version
semauri check examples/sorted.suri
semauri check examples/distinct.suri
semauri run --allow console_write examples/sorted.suri
semauri run --allow console_write examples/distinct.suri
```

Expected version: `Semauri 0.22.0`.
