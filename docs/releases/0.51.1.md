# Semauri 0.51.1 — Human-and-agent positioning and Jupyter diagnostics

This patch release improves how Semauri is presented and makes the experimental Jupyter kernel more reliable for failed cells. It does not change the Semauri language, typed compiler, or capability model.

## Included pull requests

- [#267](https://github.com/edujbarrios/semauri/pull/267): Clarify the natural-language-inspired programming language tagline in the README and Cargo package metadata.
- [#268](https://github.com/edujbarrios/semauri/pull/268): Surface stdout-only compiler diagnostics such as `%%check --json` errors and validate positive, finite cell timeouts, with offline regression tests.

## Jupyter behavior

Notebook cells remain isolated standalone programs. Only `console_write` is granted by default. Failed commands that return machine-readable diagnostics on stdout now expose the actual diagnostic as a Jupyter error, without duplicating it as a stream. Normal successful stdout remains unchanged.

Invalid values such as `SEMAURI_CELL_TIMEOUT=nan`, `inf`, `0`, or negative numbers now produce a clear kernel error before subprocess execution.

## Compatibility and distribution

- Source language version: 0.51; Semauri compiler/package version: 0.51.1.
- No new Rust or Python dependencies, syntax changes, or additional runtime permissions.
- The existing release workflow publishes the version tag `v0.51.1` and six native platform archives with SHA-256 checksums after its packaging jobs pass.
