# Semauri 0.35.0

Semauri 0.35.0 expands practical data processing while keeping its defining
contract: readable English phrases, deterministic compilation, static typing,
and explicit effect permissions.

## New capabilities

### Split and join structured text
- `split of TEXT by DELIMITER` returns a typed `list<string>` and preserves
  leading, consecutive, and trailing empty fields. Literal Unicode delimiters
  work without regular expressions.
- `join of LIST with DELIMITER` reconstructs a string from `list<string>`.
- The compiler rejects invalid operand types (`S392`). Splitting rejects
  empty delimiters and more than 10,000 fields (`S393`).
- The existing ML-domain `split` operation remains available.

### Convert text into checked values
- `parse number from TEXT` returns a `number` for signed 64-bit integers
  or finite decimal/exponent text.
- `parse boolean from TEXT` accepts `true` or `false`
  without regard to ASCII letter case.
- Surrounding whitespace is permitted. Invalid strings, numeric overflow,
  and non-finite results are errors, not silently coerced values.
- Input type errors use `S394`, and invalid parsed text uses `S395`.

These features are pure, require no extra permissions, and integrate with
constant folding where valid, the source formatter, and VS Code highlighting.
They add no dependencies.

## Example

```text
let fields be split of "12.5,true" by ",".
let amount be parse number from (fields at 0).
let enabled be parse boolean from (fields at 1).
assert amount is greater than 12.
assert enabled.
let summary be join of fields with " | ".
print summary.
```

## Installation and compatibility

Download the distribution archive for your operating system and processor,
extract it, add the Semauri executable to `PATH`, and run `semauri version`.

Packages are built for Linux, macOS, and Windows on x86_64 and ARM64.
The automated release also publishes `SHA256SUMS` for archive verification.

No existing Semauri source syntax is intentionally broken by this release.
This version does not claim a complete CSV parser (including quoted cells),
a full JSON decoder, hosted AI-provider execution, or a package manager.
Check the root README for canonical syntax and supported capabilities.
