# Semauri 0.38.0

Semauri 0.38.0 adds Unicode-aware string slicing and standards-compliant
nested JSON navigation. Both capabilities preserve statically typed,
English-readable source code, deterministic evaluation, and explicit effect
permissions.

## Unicode string slicing

The existing `take COUNT from VALUE` and `drop COUNT from VALUE` expressions
now accept strings as well as typed lists. String selections count Unicode
scalar values, not UTF-8 bytes. Their results are immutable strings.

```text
let name be "café".
assert take 3 from name is equal to "caf".
assert drop 3 from name is equal to "é".
assert take 100 from name is equal to name.
```

Counts must be nonnegative integers, with source-aware diagnostic `S364`
for invalid counts. Out-of-range counts are clamped to the source length.
Existing list behavior remains compatible. Constant string slices can be
optimized at compile time.

## Nested JSON pointer navigation

`json at pointer POINTER in DOCUMENT` selects a JSON subtree using the
standard RFC 6901 pointer format, then returns its serialized JSON text.
The result composes with Semauri's six existing typed JSON decoders.

```text
let document be "{\"users\":[{\"name\":\"Ada\"}]}".
let selected be json at pointer "/users/0/name" in document.
let name_value be decode json as string from selected.
assert name_value is equal to "Ada".
```

Pointer syntax supports nested objects, zero-based array indices, escaped
slash (`~1`) and tilde (`~0`) characters, and the empty pointer for
selecting the root value. Invalid or missing paths report `S407`;
non-string operands report `S406`. A 1 MiB JSON input limit, 64-segment
path limit, and 10,000-item selected collection limits protect pure
evaluation from excessive resource use. Existing exact top-level
`json TYPE at KEY in DOCUMENT` syntax is unchanged.

## Compiler and developer improvements

The features integrate with static type checking, execution, constant
folding, the source formatter, VS Code syntax highlighting, runnable
examples, and regression tests. No new Rust dependencies, implicit network
access, or filesystem effects have been introduced.

## Installation and downloads

The GitHub release workflow publishes packages for Linux, macOS, and
Windows on x86_64 and ARM64, plus a `SHA256SUMS` file for archive
verification. Download the correct package, extract it, add the Semauri
executable to your `PATH`, and run `semauri version`.

## Limitations

String operations count Unicode scalar values rather than locale-specific
grapheme clusters. JSON pointer navigation returns JSON text, not an
untyped mutable record; decode the result to a declared Semauri type.
An HTTP client, package management, and general first-class records remain
separate future development goals.
