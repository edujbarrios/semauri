# Semauri 0.60.0 — More natural programming

Semauri continues toward English-like syntax and Python-style expressiveness, without changing its deterministic, statically typed semantics.

- `LEFT joined with RIGHT`: string-only concatenation, compile-time checks and constant folding.
- `when ...:` / `otherwise when ...:`: conditional aliases.
- `A is different from B`: typed inequality alias.
- `for item in collection:` and `for each item in collection:` from PR #299.
- Historical PR #109 is reconciled with the Rust compiler; `is not equal to` remains supported.
- Updates to tests, editor syntax, Jupyter assistance and docs.

See `examples/natural_syntax.suri` and `docs/language-guide.md`.
