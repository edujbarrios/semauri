# Semauri 0.76.0 — Natural counting and machine-readable version

This release adds a concise natural-language count expression and a stable JSON
version response while keeping Semauri's explicit capability model intact.

## Count items or Unicode characters

```text
let tasks be a list of "design", "check", "ship".
let task_count be count of tasks.
let character_count be count of "ñ🌍".
assert task_count is equal to 3.
assert character_count is equal to 2.
```

`count of` is equivalent to `length of`, including strict static type checking,
Unicode scalar semantics, optimization and runtime behavior. It does not change
`count every x in values if PREDICATE`, and a variable may still be named
`count`.

Run `semauri check examples/count_of.suri` and
`semauri run --allow console_write examples/count_of.suri`.

## Version introspection for tools

```sh
semauri version --json
```

```json
{"name":"semauri","version":"0.76.0"}
```

Text `semauri version` is unchanged. Invalid extra version arguments now
produce a usage error instead of silently succeeding.

## Compatibility

- No new dependencies or permissions.
- No breaking changes to existing language syntax or semantics.
- Expanded integration tests for counting, contextual variable names,
  formatting, optimizer/effect analysis and CLI JSON introspection.
- Release metadata and documentation updated.
