# Semauri 0.55.0 — Multiline text, expressive fractions, and Unicode interoperability

Semauri 0.55.0 adds three backward-compatible language features to the typed,
natural-language-inspired `.suri` language, and updates editor highlighting.

## Included pull requests

- [#284](https://github.com/edujbarrios/semauri/pull/284): allow leading-dot decimal fractions like `.5` and `.25e+2` while preserving `.` as a statement terminator and located `S106` numeric errors.
- [#285](https://github.com/edujbarrios/semauri/pull/285): allow multiline literal UTF-8 text blocks in triple double quotes (`"""..."""`) or triple single quotes (`'''...'''`). Preserve embedded newlines, quotes, and backslashes literally; unterminated blocks report `S103`.
- [#286](https://github.com/edujbarrios/semauri/pull/286): accept fixed-width eight-digit `\UXXXXXXXX` Unicode scalar escapes in ordinary strings, in addition to `\u{HEX}` and `\xNN`. Invalid scalar values, surrogates and incomplete escapes report `S104`.
- [#287](https://github.com/edujbarrios/semauri/pull/287): improve VS Code/TextMate highlighting for these literals, with regression tests and documentation.

## Examples

```text
let probability_value be .75.
let symbol_value be "\U0001F600".
let prompt_value be """Answer briefly.
Keep the word "Semauri" as written.
Backslashes such as \n remain literal.""".
assert probability_value is equal to 0.75.
print symbol_value.
print prompt_value.
```

Multiline strings preserve their contents verbatim and do not process backslash
escapes. Standard quoted strings still interpret supported escape sequences.
All new expressions use existing typed compiler representations.
