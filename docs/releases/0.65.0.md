# Semauri 0.65.0 — Exact numbers, natural predicates, radix and collection functions

This release gathers the improvements merged after v0.64.0 in PRs
[#311](https://github.com/edujbarrios/semauri/pull/311),
[#312](https://github.com/edujbarrios/semauri/pull/312),
[#313](https://github.com/edujbarrios/semauri/pull/313), and
[#314](https://github.com/edujbarrios/semauri/pull/314).

## Correct numerical comparisons

- Compare signed 64-bit integers exactly for ordering, even above 2^53.
- Compare integers with decimal values near signed boundaries without silently
  rounding the integer operand through binary64.
- Keep the language's established storage-sensitive equality, list membership,
  and distinct semantics; optimizer and runtime comparisons agree.

## Readable positive and negative predicates

- `COLLECTION includes VALUE` and `COLLECTION excludes VALUE` work with
  statically typed lists and Unicode text, reusing checked membership.
- `does not contain`, `does not include`, `does not start with` and
  `does not end with` add conversational negation without double evaluation.
- `NUMBER is prime` and `NUMBER is not prime` reuse `prime of`
  and its checked integer diagnostics (S435/S436).

## Checked integer-to-text radix functions

- `binary of NUMBER`, `octal of NUMBER`, `hex of NUMBER`, and
  `hexadecimal of NUMBER` produce typed strings.
- Exact sign-magnitude formatting covers the entire signed 64-bit range,
  including the minimum value; integral finite decimals are supported.
- Invalid operand types and fractional/out-of-range inputs retain
  source-located errors S468/S469.

## Concise typed collection/statistical functions

- `avg of`, `var of`, `stddev of`, `total of`, `size of`,
  `unique of`, `head of`, and `final of` are contextual aliases
  for the existing checked average, variance, standard deviation, sum,
  length, distinct, first, and last operations.

## Tooling, compatibility and downloads

- New executable examples and regression coverage for typing, evaluation,
  optimization, formatting, errors and effects.
- Updated VS Code grammar, Jupyter completion and help, and language docs.
- All features are additive; no new Rust runtime dependencies or effect grants.
- The release workflow packages six tested binaries: Linux (x86_64/ARM64),
  macOS (x86_64/ARM64), and Windows (x86_64/ARM64), with SHA256 checksums.

See `CHANGELOG.md`, `docs/language-guide.md`, and the updated `examples/` directory.
