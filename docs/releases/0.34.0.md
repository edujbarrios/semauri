# Semauri 0.34.0

Semauri 0.34.0 adds practical, statically typed text processing, application-data
serialization, and natural-language string validation. All new operations are
pure and follow the language's deterministic compilation and explicit-effects
model.

## New language functionality

- **Text normalization:** `trim of TEXT` removes surrounding Unicode whitespace.
- **Text segmentation:** `words of TEXT` yields `list<string>` tokens; `lines of TEXT`
  yields a typed list of lines, including support for Windows CRLF input.
- **JSON encoding:** `json of VALUE` produces escaped JSON text for typed
  numbers, strings, booleans, colors and supported homogeneous lists. This is
  serialization, not JSON decoding or a general-purpose object/map API.
- **Readable text validation:** `TEXT starts with PREFIX` and
  `TEXT ends with SUFFIX` produce checked Boolean results for string operands.

All new operators preserve ordinary identifier names when their complete
natural-language phrase is not present. Invalid operands are rejected with
source-aware diagnostics. The optimizer folds constant expressions where safe,
and the formatter and VS Code grammar recognize the new syntax.

## Example

```text
let filename be trim of "  report.json  ".
assert filename starts with "report".
assert filename ends with ".json".
let words_list be words of "simple natural syntax".
let payload be json of words_list.
assert payload is equal to "[\"simple\",\"natural\",\"syntax\"]".
print payload.
```

## Installation

Download the release archive for your platform, extract it, and add the
`semauri` executable to your `PATH`. Confirm with `semauri version`.

The release pipeline publishes packages for Linux x86_64/ARM64, macOS
x86_64/ARM64, and Windows x86_64/ARM64, plus a SHA-256 checksum file.

## Compatibility and limitations

- No breaking syntax change or additional effects are introduced.
- Strings are Unicode-aware; text predicates remain case-sensitive.
- The compiler is still an evolving implementation, not a claimed replacement
  for production HTTP clients, package managers, or a complete JSON decoder.
- Provider-hosted AI adapters remain separate from deterministic local execution.

See the root README for canonical language syntax and detailed examples.
