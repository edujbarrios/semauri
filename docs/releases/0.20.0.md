# Semauri 0.20.0 — Typed Extrema and Auditable ML Plans

Semauri is an independent statically typed programming language with a Rust compiler, readable English-like syntax, deterministic lowering, domain-specific backends and explicit effect permissions. Version 0.20.0 adds numeric extrema to core-language lists and strengthens CI-backed evidence for ML workflow validation.

## Language: `minimum of` and `maximum of`

```sema
let scores be a list of 8, 3, 13, 5.
let lowest be minimum of scores.
let highest be maximum of scores.
assert lowest is equal to 3.
assert highest is equal to 13.
print highest.
```

The expressions accept a concrete typed `list<number>` and return `number` without mutating the input or adding runtime effects. Integer-only extrema compare `i64` values exactly (including beyond `2^53`); mixed floats and integers follow `f64` comparison semantics. Invalid types report `S353` at compile time; empty/non-finite operands are guarded by `S355` during evaluation. Prefix expressions bind to the next primary; larger expressions require parentheses. **Compatibility:** `minimum` and `maximum` are newly reserved words.

## AI engineering: inspectable, CI-tested workflows

```sh
semauri check examples/ml_versioned_inputs.sema
semauri graph examples/ml_versioned_inputs.sema
semauri audit examples/ml_versioned_inputs.sema --strict
```

The ML example declares dataset/model revisions and a seeded training plan. The graph exposes typed producer/consumer dependencies, and strict audit can reject missing revision and seed declarations. A dedicated CI test checks graph determinism, audit schema, example coverage and denied capabilities by default.

**Boundary:** the ML domain describes *planned* work. This release does not train models or verify actual dataset/model artifacts, external reproducibility, framework versions or GPU determinism. `verification: declarations_only` is metadata, not proof of training outcomes.

## Get started

Install the current native binary following the [installation guide](../00_INSTALLATION.md), create a `.sema` file and run:

```sh
semauri version
semauri check examples/numeric_extrema.sema
semauri run --allow console_write examples/numeric_extrema.sema
```

Expected compiler version: `Semauri 0.20.0`.

## Distribution and checks

CI compiles/tests the Rust compiler and checks native distributions for Linux x86_64/ARM64, macOS x86_64/ARM64 and Windows x86_64/ARM64. After the release workflow succeeds, the six archives and `SHA256SUMS` are available on GitHub Releases. Check the published assets and their checksums before distributing.
