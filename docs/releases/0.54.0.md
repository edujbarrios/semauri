# Semauri 0.54.0 — Compact numeric identifiers and richer string literals

Semauri 0.54.0 adds three backward-compatible literal features to the natural-language-inspired
`.suri` language, alongside improved syntax highlighting. The existing statically typed
compiler and deterministic error diagnostics remain intact.

## Included pull requests

- [#279](https://github.com/edujbarrios/semauri/pull/279): `0z`/`0Z` base-36 integer literals, underscore separators, signed 64-bit bounds and `S106` diagnostics.
- [#280](https://github.com/edujbarrios/semauri/pull/280): `\xNN` character escapes in both ordinary quote styles, representing U+0000–U+00FF with exactly two hexadecimal digits (`S104` for malformed escapes).
- [#281](https://github.com/edujbarrios/semauri/pull/281): hash-delimited raw strings, such as `r#"..."#`, `r##"..."##`, and single-quote / uppercase-`R` variants. Embedded quotes are supported, backslashes remain literal and existing `S102`/`S103` errors apply.
- [#282](https://github.com/edujbarrios/semauri/pull/282): VS Code/TextMate highlighting for all the new literal forms, with grammar regression tests.

## Language examples

```text
let serial_value be 0z1_z.
let hex_letter be "\x41".
let quotation be r#"She said "hello" and typed \n literally"#.
assert serial_value is equal to 71.
assert hex_letter is equal to "A".
print quotation.
```

Hash delimiters must match at both ends; raw strings do not interpret escapes or
allow literal newlines. Ordinary strings still support `\u{HEX}` Unicode escapes.
The formatter preserves original literal spellings.
