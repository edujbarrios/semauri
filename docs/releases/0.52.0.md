# Semauri 0.52.0 — Expressive literals and updated editor support

Semauri 0.52.0 extends the natural-language-inspired, statically typed
`.suri` language with two additive literal forms, keeping its deterministic
compiler, existing programs, and capability model intact.

## Included pull requests

- [#270](https://github.com/edujbarrios/semauri/pull/270): binary (`0b`), octal (`0o`), and hexadecimal (`0x`) integer literals with case-insensitive prefixes, underscore separators, signed 64-bit overflow checks, and located lexical diagnostics.
- [#271](https://github.com/edujbarrios/semauri/pull/271): single-quoted strings, with embedded double quotes and escaped apostrophes, while retaining Unicode and existing double-quoted strings.
- [#272](https://github.com/edujbarrios/semauri/pull/272): VS Code TextMate highlighting for the new numeric bases and quote styles, plus grammar regression tests.

## Language examples

```text
let permissions be 0b1010_0101.
let file_mode be 0o755.
let color_code be 0xFF.
let greeting be 'She said "hello".'.
assert color_code is equal to 255.
```

Numeric literals are integers and must fit a signed 64-bit value. Other
numeric syntax, including decimal fractions and scientific notation, remains
unchanged. Both quote styles use the same string escape rules and maintain
source-aware lexical diagnostics.

## Compatibility and distribution

- Language and Rust compiler/package version: **0.52.0**; the experimental
  Jupyter kernel advertises language version **0.52**.
- No new dependencies, runtime permissions or capability grants.
- The release workflow packages six native platform archives
  (Linux/macOS/Windows on x86_64 and arm64) with SHA-256 checksums.
