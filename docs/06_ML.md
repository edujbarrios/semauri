# ML semantic domain

The built-in `ml` domain describes machine-learning intent as typed compiler semantics before any framework or accelerator runtime executes a workload.

## Current types

```text
ml.dataset
ml.model
ml.device
ml.resource_budget
ml.training_config
ml.training_run
ml.inference_run
ml.evaluation_run
```

These are nominal values produced by semantic operations rather than forged from primitive strings.

## Dataset lineage

```text
Let dataset be Open dataset "./images".
Let normalized be Transform dataset using "normalize".
Let training be Split normalized ratio 0.8 seed 42.
```

Transforms and splits preserve `ml.dataset` lineage. Split ratios must be greater than zero and less than one; seeds must be non-negative integers (`S340`).

## Model construction and transforms

A model may be loaded externally:

```text
Let model be Load model "resnet18".
```

or constructed semantically:

```text
Let model be Build cnn for 2 classes input channels 3.
```

Immutable transforms produce new typed model references:

```text
Let frozen be Freeze model component "features".
Let adapted be Apply lora to frozen rank 16 alpha 32.
```

QLoRA is supported through `Adapt <model> with qlora ...` with validated 4-bit or 8-bit quantization.

## Training, inference and evaluation

```text
Within ml:
  Let dataset be Open dataset "./images".
  Let model be Load model "resnet18".
  Let device be Select device "cuda".
  Let run be Train model using dataset on device for 10 epochs.
  Let inference be Infer model on dataset using device.
  Let evaluation be Evaluate model on dataset using device metric "accuracy".
End.
```

Evaluation supports `accuracy`, `precision`, `recall`, `f1`, `loss` and `perplexity`; unsupported literal metrics report `S341`.

## Typed training configuration

```text
Let config be Configure training for 12 epochs using optimizer "adamw" learning rate 0.0003 batch size 32 seed 42.
Let run be Fit model using dataset on device with config.
```

The extended `Plan training ... precision ... accumulate ... checkpoint every ...` form records precision, gradient accumulation and checkpoint cadence in the runtime plan.

## Resource-aware planning

```text
Let resources be Budget resources memory 24 gb workers 4.
Let run be Allocate resources to fit model using dataset on device with config.
```

Memory must be positive and workers must be positive integers (`S342`).

## Inspect before execution

```bash
semauri plan train.sema
semauri effects train.sema
```

ML operations may declare `filesystem_read`, `model_load`, `compute`, `model_training`, `model_inference` and `model_evaluation`.

## Framework boundary

The reference compiler emits semantic runtime plans, not framework calls. A future executor may implement the same plan with PyTorch, Transformers, ONNX Runtime, OpenVINO, JAX or another system without changing Semauri source semantics.
