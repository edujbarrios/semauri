# ML semantic domain

The built-in `ml` domain describes machine-learning intent as typed compiler semantics before a framework or accelerator runtime executes a workload.

## Types

```text
ml.dataset
ml.model
ml.device
ml.resource_budget
ml.training_config
ml.training_run
ml.inference_run
ml.evaluation_run
```

These are nominal values produced by semantic operations.

## Dataset lineage

```text
let dataset be open dataset "./images".
let normalized be transform dataset using "normalize".
let training be split normalized ratio 0.8 seed 42.
```

Transforms and splits preserve `ml.dataset` lineage. Invalid split ratios or seeds report `S340`.

## Models and transforms

```text
let model be load model "resnet18".
let frozen be freeze model component "features".
let adapted be apply lora to frozen rank 16 alpha 32.
```

Models can also be constructed with `build cnn ...`. QLoRA supports validated 4-bit or 8-bit quantization.

## Training, inference and evaluation

```text
within ml:
  let dataset be open dataset "./images".
  let model be load model "resnet18".
  let device be select device "cuda".
  let run be train model using dataset on device for 10 epochs.
  let inference be infer model on dataset using device.
  let evaluation be evaluate model on dataset using device metric "accuracy".
end.
```

Evaluation supports `accuracy`, `precision`, `recall`, `f1`, `loss` and `perplexity`; invalid literal metrics report `S341`.

## Training configuration and resources

```text
let config be configure training for 12 epochs using optimizer "adamw" learning rate 0.0003 batch size 32 seed 42.
let resources be budget resources memory 24 gb workers 4.
let run be allocate resources to fit model using dataset on device with config.
```

The extended `Plan training ... precision ... accumulate ... checkpoint every ...` form records precision, gradient accumulation and checkpoint cadence. Resource validation reports `S342` for invalid budgets.

## Version-qualified model and dataset declarations

```sema
within ml:
  let dataset be source dataset "./images" revision "dataset-v3".
  let model be resolve model "resnet18" revision "weights-v2".
  let device be select device "cpu".
  let config be configure training for 3 epochs using optimizer "adamw" learning rate 0.0003 batch size 16 seed 42.
  let run be fit model using dataset on device with config.
end.
```

The required revisions are **declared identifiers only**. The compiler does not fetch or checksum files; an external adapter must verify actual model/dataset bytes. See [version-qualified inputs](19_ML_VERSIONED_INPUTS.md).

## Inspect before execution

```bash
semauri plan train.sema
semauri effects train.sema
semauri graph train.sema
semauri audit train.sema --strict
```

ML operations may declare `filesystem_read`, `model_load`, `compute`, `model_training`, `model_inference` and `model_evaluation`.

The `graph` command exports validated, typed SSA dependencies; `audit` emits reproducibility-declaration warnings and returns exit code 2 in strict mode for incomplete declarations. See [dataflow graphs](18_ML_DATAFLOW.md) and [ML audit](20_ML_AUDIT.md).

The reference compiler emits semantic runtime plans, not framework calls. It does not train models or certify reproducibility. Execution frameworks and artifact verification belong behind the runtime boundary.
